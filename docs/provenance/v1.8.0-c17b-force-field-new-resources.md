# Original force-field resources

The W04 projector and technical field models, textures, recipes and loot are
original community implementation resources. Textures are generated from new
pixel grids in `V180ForceFieldData`; models reference the vanilla cube model
contract, not copied Minecraft artwork. No upstream code or asset is imported.
Stable IDs are `advancedrocketrycommunity:force_field_projector` and
`advancedrocketrycommunity:force_field`. The technical field has no item or loot.
