## Review scope

The legacy Electrolyser recipe and machine classes were used only to identify
the player-visible concept of splitting water into hydrogen and oxygen. The
v0.2.0 implementation is new Java 17 / Forge 1.20.1 code with a different
single-block architecture, bounded recipe format, gas-canister outputs,
server-authoritative processing, and schema-versioned persistence.

Behavior-reference inputs:

- `src/main/resources/assets/advancedrocketry/recipes/hydrogenoxygen.json`
- `src/main/java/zmaster587/advancedRocketry/tile/multiblock/machine/TileElectrolyser.java`
- `src/main/java/zmaster587/advancedRocketry/recipe/RecipeElectrolyser.java`

All three are bound to the approved MIT upstream commit above. No source bytes,
class structure, texture, model, sound, or other binary asset were copied or
transformed into this version.

## Community-authored and runtime-referenced resources

The complete generated-resource inventory is
[`v0.2.0-generated-resources.json`](v0.2.0-generated-resources.json). Its JSON
models and language text are community-authored. Models refer by resource ID to
Minecraft's runtime-provided `minecraft:block/sea_lantern` and
`minecraft:item/glass_bottle` textures; those texture bytes are not stored in
this repository or release JAR.

The `src/generated/resources` tree remains the byte-exact, approved v0.1.0
snapshot. New DataGen outputs are isolated under
`src/generated/v0.2/resources`, preventing later content from rewriting
historical provenance targets.
