# v1.8 propulsion source and art provenance

The propulsion code, JSON blueprints, translations and 16-by-16 hardware textures
in `V180PropulsionData`, `V180PropulsionLanguage` and `V180PropulsionArt` are new
community work under this repository's MIT license. The art uses only original
pixel geometry and color constants; no image input, upstream bitmap, Minecraft,
Mojang or Forge artwork is copied or transformed.

The generated cohort is the eight propulsion block IDs in `V180PropulsionData.IDS`,
their item/block models, blockstates, loot, crafting recipes, recipe advancements,
movability tag and four `rocket_fluid_fuels` definitions. Vanilla model parents
and crafting ingredient identifiers are references, not copied art.

The existing community arithmetic `RocketPropulsionNumbers` and canonical native
framer `RocketNativeFrame` are reused unchanged. Numeric behavior follows ADR-065
and the accepted numeric decision; no upstream source file is imported here.
