## Community-authored changes

The migration transaction, bounded diagnostics, packet hardening, optional JEI
adapter, release-test hooks, harnesses, validators, tests, and documentation are
new community-authored work. No source or binary asset was copied from the
original Advanced Rocketry project or from another community fork for v0.9.0.

The accepted v0.8.0 gameplay resources remain governed by their existing
versioned provenance manifests. The v0.9.0 frozen implementation changes no
core source or generated asset path. Deterministic DataGen and the dedicated
resource audit verify the inherited inventory.

## Optional JEI dependency

The compatibility adapter compiles against the official JEI 1.20.1 public API,
version `15.56.0.205`, from the official Maven repository. JEI is MIT-licensed,
is optional and client-only, and is not embedded in the ARCE JAR. Exact Maven
coordinates, resolved SHA-256 values, license URL, and license hash are recorded
in [`THIRD-PARTY-NOTICES.md`](../../THIRD-PARTY-NOTICES.md).
