## New community-authored work

Every planned sound is NEW MIT work, synthesized by deterministic Java code in a
DataGen provider. The only inputs are numbers written in that source file:
oscillator frequencies, envelopes, filter coefficients and the seeds of a
project-written pseudo-random generator. No recording, sample, sound font,
impulse response or downloaded file is used. Synthesis uses `StrictMath` so the
bytes are reproducible on every platform.

The OGG files are written by a NEW Java Ogg Vorbis I encoder written for this
project from the public Xiph.Org Vorbis I specification and the Ogg
encapsulation (RFC 3533). No libvorbis, stb_vorbis, FFmpeg or other codec source
is copied or linked, and no external tool runs. The encoder uses one block size,
floor type 1 and residue type 1 with uniform 8-bit lattice codebooks: simple,
not efficient. Output is mono at 22,050 Hz.

Planned sound designs (parameters are tuned in code before the first commit of
the generated files):

| Event ID | Kind | Planned synthesis |
| --- | --- | --- |
| `air_hiss_loop` | loop | band-limited noise with a slow flutter, made periodic so the loop has no seam |
| `basic_laser_gun` | one-shot | a falling square-ish zap with a short noise burst |
| `combustion_rocket` | loop | low rumbling noise with a periodic low-frequency roar |
| `electric_shock_small` | one-shot | a few short crackle bursts of noise with fast decay |

Loop waveforms are periodic over the file length, which is a whole number of
Vorbis half-blocks, so the decoded loop repeats without a gap.
`lathe` and `rolling_machine` get two distinct NEW files; ADR-066 only permits,
and does not require, sharing one approved file.

## Verification planned before delivery

- Unit tests decode every generated file with LWJGL `stb_vorbis`, the decoder
  Minecraft 1.20.1 uses, and check that it is audible (peak and RMS above
  fixed floors), the expected length and close to the synthesized waveform.
- Unit tests check that every registered event has a `sounds.json` entry and
  that every referenced file exists.
- There is no OGG screening tool in this repository. The origin evidence for
  these files is this record, the generator source and its hash, and the
  absence of any input file. That limit is recorded, not waived.
- A manual listen by the owner or a named reviewer is still required (ADR-066
  section 7.1); an automated waveform check does not replace it.

All entries remain pending maintainer listening and license review. No asset
approval, legacy import, origin-finding change or Required Gate follows from
this record.
