# v1.8 station controllers: NEW resource declaration

Declared with task W07 on 2026-10-12. Status: NEW, implemented, not visually accepted.
License: repository MIT. Attribution: Advanced Rocketry: Community Edition contributors.

## Independent origin

The stable content IDs are `advancedrocketrycommunity:warp_controller`,
`station_gravity_controller`, `station_altitude_controller` and
`station_orientation_controller` under ADR-065 section 2. Their six fully opaque 16 x 16
RGBA faces are drawn by code in `datagen/V180StationControlData.java`:

- a shared top plate with vents;
- a shared bottom plate;
- one side panel per controller, a framed screen with its own glyph: a chevron (warp), a
  downward arrow (gravity), an upward arrow with rungs (altitude) and a ring (orientation).

The grids are new. They reuse only the repository's existing `V180MaterialArt.png`
encoder. No upstream, LibVulpes, Minecraft/Mojang/Microsoft/Forge or third-party image
is read, traced, sampled, cropped, recoloured or imported. The legacy controller
textures stay excluded.

## Models, data and language

- **Models.** The block models reference `minecraft:block/cube_bottom_top` by identifier
  only and use the new community textures. The item models reference the block models.
- **Data.** Blockstates, the self-drop loot tables, the shaped recipes and the
  recipe-unlock advancements are new modern JSON. The recipes use steel plates,
  `user_interface`, `control_board` and one circuit part per controller. They make no
  claim of legacy parity.
- **Language.** The English and Chinese names, the screen strings and the station code
  keys are new.

Paths are written by `runData` into `src/generated/v1.8/resources`.
