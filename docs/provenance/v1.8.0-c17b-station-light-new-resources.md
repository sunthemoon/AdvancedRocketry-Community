## Independent origin

The stable content ID is `advancedrocketrycommunity:station_light` under
ADR-065. Its new fully opaque 16 x 16 RGBA face is independently drawn as a
pale illuminated centre with a grey metal housing. No upstream, LibVulpes,
Minecraft/Mojang/Microsoft/Forge or third-party image is read, traced, sampled,
cropped, recoloured or imported. The excluded legacy
`textures/blocks/stationlight.png` remains excluded.

The new source grid is owned by the prospective
`datagen/V180StationLightData.java`. It reuses only the repository's existing
`V180MaterialArt.png` encoder, not any existing art grid. Output is
`src/generated/v1.8/resources/assets/advancedrocketrycommunity/textures/block/station_light.png`.
The independently reviewed source uses a new stepped frame/inset-panel grid and
tint `0xE8EDF2`. The existing encoder is unchanged. Source and provisional-byte
observations are recorded in the [implementation record](../work/v1.8.0-c17b-station-light/SOURCE-VERIFICATION-01.md);
they do not establish compilation or native DataGen equality.

## Models, data and language

The NEW modern cube model references `minecraft:block/cube_all` by identifier;
it does not copy an official model body or bitmap. All six faces reference only
the new community texture. The matching item references the new block model.
The blockstate, one-self-item loot, shaped four-lamp recipe and recipe-unlock
advancement are newly authored modern JSON. Inputs are existing vanilla registry
IDs; the recipe does not claim legacy parity. The bilingual name is newly
authored `Station Light` / `空间站灯`.

Exact paths and behavior are frozen in
[C17b-LIGHT-01](../work/v1.8.0-c17b-station-light/TASK.md) and its immutable
specification. Existing language/tag members are retained. Source/output review
does not clear other REVIEW assets, native/client acceptance or release Gates.
