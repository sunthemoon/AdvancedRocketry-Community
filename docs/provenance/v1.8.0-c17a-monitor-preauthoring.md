# Rocket monitoring station: pre-authoring declaration

Declared 2026-10-24 at `a2b1baecf`, before W153 implementation or resource authoring.
Scope follows [W153](../work/v1.8.0-root-queue/records/W153.md) and ADR-065 sections
4.2, 4.3 and the R92 protocol implementation note.

NEW original MIT code: the monitor model, bounded metadata codec, binding/pad adapters,
server/menu/client logic, shared flight-entry integration and tests. Existing project
utilities and the linker's already-provenanced selection, icon and recipe are reused.
NEW text and art: English/Chinese monitor names, labels, feedback, original code-drawn
16x16 screen/case textures and a code-drawn menu. No upstream implementation or asset
is used as an authoring input.

GENERATED output belongs only to `src/generated/v1.8/resources`: blockstate, block/item
models, textures, loot, recipe/unlock advancement and language entries. The monitor's
community recipe uses tracking circuitry, a control board, a user interface and a
machine casing. Vanilla model parent IDs are references, not copied files. The existing
project PNG encoder is reused; target/generator hashes follow after generation.

No LibVulpes, Minecraft, Mojang, Microsoft, Forge or third-party code, bitmap, model or
text is copied, traced or sampled. Attribution is to Advanced Rocketry: Community
Edition contributors; author is the Codex W153 implementer. Independent code review,
human originality approval and V1/V2 remain pending. The unchanged vanilla-art screen
and provenance checker are verification, not human visual approval.
