# Sealed rocket carrier: pre-authoring declaration

Recorded on 2026-10-24 before authoring the carrier artwork. The carrier will use
one original 16-by-16 opaque texture, identical on all six faces. It will depict
a closed dark metal panel with an amber restraint band; it will not reveal the
original block or its contents. Pixel geometry and colors will be defined in
`V180SealedRocketData`, without bitmap inputs, tracing or transformed assets.

This is new community work under the repository's MIT license. No upstream,
Minecraft, Mojang, Microsoft, Forge or third-party artwork is copied. The vanilla
cube model parent is a resource reference, not copied artwork. The generated
blockstate, model, texture and immunity tags belong only to the v1.8 output root.
The carrier has no item model, recipe, loot or creative-tab entry. Bilingual block
text describes a sealed member, not an accessible container or a repair tool.

## Authored source

`V180SealedRocketData` now defines the 16-by-16 pixel grid and seven opaque colors.
It uses the existing project's PNG encoder, not an existing image. The central
amber restraint crosses a closed steel-grey panel; the same `cube_all` texture
covers every face. The provider emits only the blockstate, block model, texture
and additive immunity/forbidden tags. Earlier project tag entries are retained
unchanged and in order. `V180LanguageProvider` supplies the two block labels.
The source tests check PNG dimensions, opacity, determinism, identical-face model
selection and preservation of the older tag entries. Native client appearance
and generated-file verification remain separate acceptance evidence.
