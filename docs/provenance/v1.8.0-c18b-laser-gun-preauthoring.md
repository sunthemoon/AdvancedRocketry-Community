# Basic laser gun source registration

Date: 2026-10-13. Scope: W20, C18b `basic_laser_gun`.

The item behaviour is a new MIT implementation of ADR-066 section 5.3, not a
copy of legacy Java. The ledger row `item:basicLaserGun` points to ranged mining
with events and protection. The behaviour reference is the committed content
audit section 3.6 and the manifest entry for
`src/main/java/zmaster587/advancedRocketry/item/tools/ItemBasicLaserGun.java`
(SHA-256 `dc62f1292efa99e0dacf9de4fd49d0d6507c4053cc5266cda218b9888ffc1bd7`,
original Advanced Rocketry MIT commit
`c5cd5af62fc07cd4e0d24f06a16033f181c47c04`). No legacy code, model, texture,
LibVulpes asset or official asset will be copied.

The ledger does not specify a recipe. The recipe manifest contains no basic
laser gun recipe. W20 will author a new shaped acquisition recipe using existing
steel plates, iron rods, a diamond and the basic circuit plate. It is not
claimed as legacy recipe parity.

New MIT resources will be generated by `V180LaserGunData`: an original 16 by 16
pixel side-view gun drawn with the existing project PNG encoder; a model that
references `minecraft:item/handheld` by ID; a shaped recipe and recipe-unlock
advancement. Bilingual names, usage, main-hand restriction and disabled feedback
will be additive keys in the v1.8 language namespace. Generated target hashes
and source identity will be recorded after generation. Asset and real-client
visual/audio approval remain for Root and the owner.

The existing W16 `basic_laser_gun` sound and its provenance are reused unchanged.
