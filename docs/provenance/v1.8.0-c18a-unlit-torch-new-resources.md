provider exists. Classification NEW: original repository-authored MIT work, not an upstream
import. No grid, pixel or asset is authored or cleared by this declaration.

(`minecraft:block/template_torch`, `minecraft:block/template_torch_wall`) are referenced by
identifier, not copied. The blockstate, model, loot and tag JSON is new.

separately. No asset, content-unit, Gate or release acceptance is claimed.
