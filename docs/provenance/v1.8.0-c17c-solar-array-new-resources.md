# Original solar array resources

Declared before source and grid authoring: 2026-10-12. License: repository MIT.
Attribution: Advanced Rocketry: Community Edition contributors.

The W17 solar array (`advancedrocketrycommunity:solar_array`), its collector
(`advancedrocketrycommunity:solar_array_panel`) and the output interface
(`advancedrocketrycommunity:power_output_plug`) use newly authored Java adapters,
layout evaluation, scalar menu, client screen, recipes, loot, tags and strings. No
upstream source body, LibVulpes implementation, or official or third-party bitmap or
model body is copied. The 1-by-22-by-3 layout is the legacy behavioral fact pinned in
ADR-065 section 1, not copied code.

Textures are new 16 x 16 opaque pixel grids in `datagen/V180SolarArrayData.java`,
encoded by the existing `V180MaterialArt.png` helper. Models reference vanilla cube
parents by resource identifier only. The screen draws original GUI primitives and
imports no texture sheet. The recipes are new technical selections from glass,
silicon wafers, copper, iron plates and the machine casing; they make no claim of
legacy grid parity.

All generated output is under `src/generated/v1.8/resources`.
