# Original landing-pad implementation and resources

The `station/pad` package, named-pad transfer integration, associated tests and
`datagen/V180LandingPadData.java` are original MIT-licensed ARCE code for ADR-065
section 6.1. The generator creates the landing-pad model, item model, blockstate,
16-by-16 raster texture, loot and recipe without importing upstream files or
Minecraft, Mojang, Microsoft or Forge artwork. The recipe references
`minecraft:gray_concrete` by registry ID only. English and Simplified Chinese
labels and messages are original. Generated resources live under
`src/generated/v1.8/resources`; their reproducible source is the generator.

This declaration precedes creation of the runtime files. It does not close a
legacy asset review, content-ledger row or release Gate.
