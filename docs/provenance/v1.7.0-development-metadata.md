## C11a (2026-10-01): endgame framework, API 1.8 and v1.7 DataGen

This record authorizes:

- `build.gradle`: an independent `compileEndgameApiJava` task for the two
  API 1.8 types (`api.endgame.EndgameEffect`, `EndgameEffectEvent`, ADR-054
  §5.1), their place in the API classifier, and the adapter-test classpath.
  **Retained ordering defect:** this edit was committed in `fedcb1d` before
  this record existed; it is recorded here, unchanged.
- `build.gradle`: the DataGen output moves to `src/generated/v1.7/resources`,
  v1.6 joins the `--existing` inputs, `src/generated/v1.7/resources` becomes a
  resource directory, and the v1.6 copies of the two vanilla tool tags are
  excluded from `processResources` and `sourcesJar`, because the complete v1.7
  copies (which add the endgame casing) supersede them.
- `.gitignore`: the v1.7 DataGen cache exclusion.
- `gradle.properties`: the repository-authored development version change
  from `1.6.0-dev` to `1.7.0-dev`, a description of the first v1.7 slice and a
  modification-date notice in the header.

No original notice, license, historical audit digest or imported resource is
replaced. The version change is not a release approval. The endgame framework,
its codecs, commands and tests are original repository MIT work.

The generated v1.7 resources and their generators are original repository MIT
work: the endgame casing model is composed from the existing project
machine-casing textures and a referenced vanilla texture, and the laser lens
item model names a vanilla item model as its parent, so no texture bytes are
copied; recipes, loot, tags and translations are repository-authored.
