# Single solar generator: NEW source and resource declaration

Declared before source/grid authoring: 2026-10-06. License: repository MIT.
Attribution: Advanced Rocketry: Community Edition contributors.
Status: NEW, proposed; no source implementation, asset import or Gate approval.

## Original work

The reserved ADR-065 IDs `solar_generator` and `solar_panel` use newly authored
modern Java adapters, calculation, bounded native-root validation, scalar menu,
client screen, recipes and resource data. No upstream source body, LibVulpes
implementation, official or third-party bitmap/model body is copied.
Existing community utilities may be called without importing other assets.

The prospective `datagen/V180SolarData.java` owns four independent opaque
16 x 16 face grids: a photovoltaic blue collector with a metal frame, matching
generator side/bottom housing and a panel. The existing `V180MaterialArt.png`
encoder is reused unchanged, not its existing art grids. Exact pixels and
output hashes are recorded only after authoring and independent review.
The screen uses original GUI primitives rather than an imported texture sheet.

## Exact output scope

All new output is under `src/generated/v1.8/resources`:

- `assets/advancedrocketrycommunity/blockstates/{solar_generator,solar_panel}.json`;
- `assets/advancedrocketrycommunity/models/block/{solar_generator,solar_panel}.json`;
- `assets/advancedrocketrycommunity/models/item/{solar_generator,solar_panel}.json`;
- `assets/advancedrocketrycommunity/textures/block/solar_generator_{top,side,bottom}.png`;
- `assets/advancedrocketrycommunity/textures/block/solar_panel.png`;
- `data/advancedrocketrycommunity/loot_tables/blocks/{solar_generator,solar_panel}.json`;
- `data/advancedrocketrycommunity/recipes/{solar_generator,solar_panel}.json`;
- matching `data/advancedrocketrycommunity/advancements/recipes/building_blocks/` entries.

Models reference vanilla cube parents by registry/resource identifier only;
no official model or bitmap bytes are copied. The recipes are new modern
technical selections, not a claim of legacy grid parity. Bilingual names are
Solar Generator / 太阳能发电机 and Solar Panel / 太阳能板. Root adds only these
IDs and new solar strings to existing generated tool tags and language files.
Native shaped recipes provide recipe-book acquisition; no JEI plugin or sound
import is included.

This pre-authoring declaration does not clear legacy REVIEW assets, prove
native DataGen equality, validate in-game visuals or close ledger entries.
Source, generated bytes, provenance and real V1/V2 remain separate checks.
