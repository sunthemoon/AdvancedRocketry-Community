## KI-V180-FALL-01 — 特定坐骑及乘客的跌落伤害未按星球重力缩放

马、驴、骡、羊驼、骆驼以及由它们承载的直接或间接乘客，在其他星球上仍可能承受原版、
未按本模组重力系数缩放的跌落伤害。低重力不保证这些实体跌落时受到更少伤害；原版自身的
伤害规则与免疫仍适用。这不是所有生物的跌落行为，也不承诺其他模组坐骑会触发 Forge 事件。

原因是 `AbstractHorse.causeFallDamage`（包括骆驼）及羊驼的覆盖方法不发出 `LivingFallEvent`，
而是直接处理自身和间接乘客的伤害。[W38](../../work/v1.8.0-root-queue/records/W38.md)
的 `horseFamilyLandingPostsNoForgeFallEventAndStaysNative` GameTest 以真实马落地及牛乘客证明
未发事件和原版伤害；其余所列物种的范围依据 W38 的方法审查，真实客户端仍待逐项确认。

所有者 D11 接受其为 v1.8 已知限制，不新增 Mixin，也未授权扩展 ADR-073。
玩家应避免让这些坐骑或乘客从高处落下，不把低重力当作防摔保证。
最终候选真实客户端仍须逐一确认这些物种及乘客的离地、落地和实际伤害，记录对照距离、
生命值、环境重力、候选 commit/JAR hash、测试人、日期与视频；涉及多人乘客时保留 V2 证据。
验收状态：最终候选的真实客户端伤害确认待执行；v1.8 保留上述原版伤害规则。

## KI-V180-MOON-01 — 月球保留固定午夜外观

v1.8 月球使用固定午夜的维度时间/天空外观规则，不显示随普通日夜周期推进的月球白昼。
月球维度类型的 `fixed_time` 为 `18000`，而非所有世界计时器被冻结或世界总 tick 停止。
该规则不改变已接受的睡眠/重生政策，也不重新打开月球 heightmap 着陆规则。

所有者 D12 选择在 v1.8 保留此外观。验收状态：最终候选 V1 待执行。
最终候选真实 GPU 客户端仍须观察月球跨时间与重新进入时的午夜外观，并同时确认代码天空、
黑洞和地球盘；保留候选 commit/JAR hash、GPU/驱动、测试人、日期、预期与实际截图/录像。
若日后调整，需另行定义天空、维度时间与睡眠影响，本条不预先授权行为变更。
