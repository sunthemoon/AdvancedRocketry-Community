# v2.0.0 — Classic Feature Parity Stable


> 平台：Minecraft 1.20.1 / Forge / Java 17
> 版本策略：实现、审核和人工批准分离
> 适用规约：`AGENTS.md`、`docs/05-MASTER-TEST-PLAN.md`、`docs/06-RELEASE-AND-ACCEPTANCE-GATES.md`、`docs/14-PARALLEL-DEVELOPMENT-AND-WORKTREE-COORDINATION.md`、`docs/17-V1PLUS-QUALITY-BUDGETS.md`


## 1. 版本目标

发布第一个经过完整功能矩阵、长期升级链、真实多人、真实 GPU、模组包、性能和安全验证的经典功能对等稳定版。

### 玩家可见结果

- 获得现代 Forge 1.20.1 上完整、稳定、可维护的 Advanced Rocketry 社区体验。
- 可从受支持 v1.x 世界升级。
- 功能对等、重设计和明确不迁移项都有公开说明。

## 2. 前置 Gate

- [ ] `v1.9.0` PASSED。
- [ ] 所有 v2.0 contracts 和 Feature Freeze 生效。
- [ ] 外部 Beta 阻断问题关闭。
- [ ] 发布负责人、独立审核者和安装测试者就位。

前置版本未 `PASSED` 时，本版本只允许只读审计、测试设计和数据样例，不提前实现功能。独立 worktree 不豁免 AGENTS 的版本范围限制。

## 3. 本版范围

- 最终版本、文档、支持和迁移承诺。
- 全 G0–G9。
- 可重现 JAR/source/hash/tag/Release。
- 最终 PORTING_MATRIX 和功能对比。
- v1.x 升级路径。
- reference modpack 和服务器运维指南。
- v2.0.x 修复政策与下一代路线。

## 4. 明确不做

- 不声称官方续作。
- 不声称二进制或 1.12.2 世界兼容。
- 不在 release commit 新增功能。
- 不承诺矩阵外所有模组组合。
- 不修改已发布 tag。

任何非目标若要提前，必须单独 ADR，明确存档、网络、兼容、安全和回退影响。

## 5. 本版待冻结契约

- v2.0 save schema/API/network/content 进入稳定支持期。
- 破坏性变更必须进入未来主版本并提供迁移。
- 公开 API 遵守弃用政策。
- Release 制品与 tag 不可变。

契约冻结后，下游任务只能通过变更提案请求调整，不能在各自 worktree 中自行改变公共语义。

## 6. 详细实施顺序

1. 从 v1.9 PASSED commit 建立 release branch。
2. 关闭所有阻断问题并执行回归。
3. 从干净 checkout 重跑全部自动、迁移、专服、视觉、多人和性能 Gate。
4. 由未参与开发者从公开文档安装客户端/服务器。
5. 核对 PORTING_MATRIX 每行状态和 ADR。
6. 生成最终 CHANGELOG、Known Issues、migration/support/admin docs。
7. 从干净候选 commit 重建并比较 SHA-256。
8. 独立审核 G0–G9 和供应链。
9. 人工批准且证据完整后创建不可变 tag，从 tag 重建核对同一 SHA-256 后发布。
10. 发布后监控并准备 v2.0.1 安全/稳定修复流程。

## 15. 必须归档的证据

- `docs/releases/v2.0.0/` 全套。
- final PORTING_MATRIX。
- feature comparison。
- migration matrix。
- reproducible build/hash。
- multi-GPU/multiplayer/soak reports。
- security and provenance review。
- public release page capture。

推荐目录：

```text
docs/releases/v2.0.0/
```

通用证据文件沿用 `MANUAL-TEST.md`、`PERFORMANCE.md`、`checksums.txt` 和
`GATE-STATUS.md`；新增迁移、视觉、安全等专项报告作为补充，不替代原 G0–G9 证据。

## 16. 推荐 PR 拆分

- PR 1：release freeze/docs。
- PR 2：final migration/repro tooling。
- 每个阻断修复独立 PR。
- PR Final：版本、证据、hash；不含新功能。
- 人工：tag 和 GitHub Release。

每个 PR 均附：范围、非目标、迁移影响、命令实跑结果、证据路径和回退方式。

## 17. 失败与回退

- 发布后 Critical 立即停止推荐并发布公告。
- 不修改 v2.0.0 tag/JAR；通过 v2.0.1 修复。
- 存档修复工具先作用于副本。
- 无法满足对等声明时延迟发布，不降低定义。
