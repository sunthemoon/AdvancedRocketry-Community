# v1.4.0 — Planetary Expansion


> 平台：Minecraft 1.20.1 / Forge / Java 17
> 版本策略：实现、审核和人工批准分离
> 适用规约：`AGENTS.md`、`docs/05-MASTER-TEST-PLAN.md`、`docs/06-RELEASE-AND-ACCEPTANCE-GATES.md`、`docs/14-PARALLEL-DEVELOPMENT-AND-WORKTREE-COORDINATION.md`、`docs/17-V1PLUS-QUALITY-BUDGETS.md`


## 1. 版本目标

在数据驱动扩展内核上恢复多行星探索、环境参数、星图和天空表现，证明新增天体已成为内容工作而不是核心代码改造。

### 玩家可见结果

- 可在地球/月球之外探索至少两类差异明显的行星或卫星。
- 星图展示天体关系、可达性和环境。
- 重力、大气、温度/太阳强度和天空随天体变化。

## 2. 前置 Gate

- [ ] `v1.1.0` PASSED。
- [ ] `v1.3.0` environment/API PASSED。

- [x] 维度/共享实例策略 ADR 完成：ADR-031；跨重启 body/Level 绑定在开放新世界前另行冻结。

只读审计、测试设计和数据样例。独立 worktree 不豁免 AGENTS 的版本范围限制。

## 3. 本版范围

- 多天体数据 schema 扩展。
- 至少 Mars-like、Venus-like 和 gas-giant definition/不可着陆示例。
- 天体环境：重力、大气、温度、太阳强度、辐射占位。
- 星图/目的地 UI。
- 数据驱动路线、发现和解锁。
- 天空、太阳、星空、雾和环境声音。
- 天体数据包原子重载与错误回滚。
- 行星资产分批来源 ledger。

## 4. 明确不做

- 不在运行中任意注册新 Minecraft 维度。
- 不实现完整地球化。
- 不实现多恒星跃迁；留给 v1.5。
- 不一次导入全部旧行星资产。

任何非目标若要提前，必须单独 ADR，明确存档、网络、兼容、安全和回退影响。

## 5. 本版待冻结契约

- 天体定义不等同于维度注册。
- 可着陆、轨道、气态巨行星等能力显式声明。
- 服务端环境值为权威，客户端只渲染同步摘要。
- 数据包错误保留上一有效 catalog。
- 资产来源按批次可追踪。

契约冻结后，下游任务只能通过变更提案请求调整，不能在各自 worktree 中自行改变公共语义。

## 6. 详细实施顺序

1. 冻结环境 schema 和 capability flags。
2. 实现数据验证、默认值、数值范围和 catalog reload transaction。
3. 加入测试 Mars/Venus/gas giant 定义和路线。
4. 实现 surface/instance 映射，不让内容层直接创建动态 registry。
5. 扩展生命支持/装备对不同环境的响应。
6. 实现星图数据模型和服务端过滤。
7. 实现客户端天空和环境渲染适配。
8. 接入发现/研究解锁。
9. 迁移旧 celestial definition 和 station orbit data。
10. 逐批导入审计资产，运行资源验证。
11. 完成真实 GPU 多天体视觉和性能测试。

## 7. 可并行工作流

| 工作流 | 允许写入 | 依赖/说明 |
|---|---|---|
| Data/schema | `celestial/data/**` | 先冻结 |
| Environment simulation | `celestial/environment/**` | 与 UI 并行 |
| World mapping | `dimension/**` | 集成独占关键注册 |

中央注册、版本、网络总入口、Gradle、`mods.toml` 和状态文件由集成任务独占。

## 8. 存档、网络与数据迁移

- 旧 Earth/Moon/space definitions 映射到新 schema。
- 未知新增字段使用明确默认，不改变旧世界环境。
- 站点 orbitBodyId 保持。
- 数据包移除已访问天体时安全拒绝进入并保留存档。
- 客户端 catalog cache 版本失配时全量重同步。

- [ ] 真实 GPU 检查每个天体天空、雾、太阳、星图和环境提示。

## 17. 失败与回退

- catalog reload 失败保留上一有效版。
- 移除天体先进入 deprecated，不立即删除玩家资产。
- 天空渲染失败回退保守默认且记录错误，但服务端环境不改变。
- 资产批次可独立回退。
