# v1.1.1 — Expansion Kernel Maintenance

> Platform: Minecraft 1.20.1 / Forge / Java 17
> Scope: behavior-preserving maintenance after the v1.1.0 implementation commit

## 1. Goal

Remove the size debt recorded by ADR-014 before v1.2 feature work. Keep the
v1.1.0 travel, persistence, authority and player behavior contracts unchanged.

## 2. Prerequisite

- v1.1.0 implementation commit: `da3e6efbc933034186d27b1809756d67cedc7b30`.
- v1.1.0 evidence checksum correction: `caf251e3540b6f24a4939edece39fecfe8fb249e`.
- Formal v1.0/v1.1 release Gates remain `IN_PROGRESS`; ADR-015 permits
  implementation order only and does not approve a release.

## 3. Required scope

- Split `RocketManager` into focused services while preserving its public API.
- Split `RocketFlightGameTests` into focused scenario classes and shared
  fixtures while preserving every registered test name and batch.
- Keep every hand-written Java class below 800 lines; production classes in
  this slice should remain below 500 lines.
- Prove behavior preservation with the complete unit and Forge GameTest suites.

## 4. Explicit non-goals

- No new travel targets, routes, celestial bodies, machines or player content.
- No save-schema, network-protocol, registry ID or data-format changes.
- No balance, timeout, scan-budget or security-limit changes.
- No long soak, remote Linux, real-GPU or two-client acceptance run in this
  maintenance implementation pass.
- No v1.2 machine/multiblock implementation.
