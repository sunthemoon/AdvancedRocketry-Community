## Corrections made during verification

- One initial DataGen run failed to fetch a Minecraft sound asset from the Mojang CDN. A retry downloaded the missing asset and subsequent runs passed.
- The first GameTest launch rejected the generated structure because `size` used an NBT int array. The provider now writes Minecraft's list-of-int structure schema plus one explicit air block; the rerun passed.
- The first Linux baseline CI run reached the clean DataGen check after successful build, JAR audit, side scan, and DataGen, then detected that its setup step had changed `gradlew` from mode `100644` to `100755`. The wrapper executable bit is now stored in Git so the setup step is idempotent.
- The first packaged-server harness attempt correctly started the server but read
  Forge's intentionally empty legacy status mod list. The final decoder follows
  Forge 47.4.10's optimized `forgeData.d` format and verifies the exact marker.
- The initial disposable flat-world property omitted generator layers and caused
  a Minecraft `No key layers` ERROR. The final harness uses a normal disposable
  world; the successful first-start and restart logs have zero ERROR findings.
- One intermediate Forge installer attempt failed after a
  `libraries.minecraft.net` read timeout. The harness now retains each attempt's
  log and permits up to three explicit retries; the final recorded run installed
  successfully on its first attempt.
