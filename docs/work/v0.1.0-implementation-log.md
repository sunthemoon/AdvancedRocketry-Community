## Goal

Deliver the complete v0.1.0 asset and registry baseline: a reproducible audit of
the exact Advanced Rocketry 1.12 upstream tree, enforceable provenance records,
a deterministic namespace/import pipeline, and a small visible Forge content
slice whose generated resources load on client and dedicated server.

## Scope and non-goals

In scope:

- exact-commit Java and asset manifests with stable ordering and risk indexes;
- provenance schema, imported-target hash validation, and CI enforcement;
- one inert machine casing, four development materials/components, one sound,
  a dedicated creative tab, and English/Chinese names;
- generated blockstates, models, loot, recipes, tags, languages, and sounds;
- unit, asset/reference, registry GameTest, packaged-server, and manual visual
  evidence required by the v0.1.0 Gate.

Explicit non-goals:

- no machine processing, inventories, energy, fluid, menu, or screen;
- no dimensions, atmosphere, suits, rockets, stations, satellites, or research;
- no LibVulpes code or assets, OBJ/MTL import, dynamic registry framework,
  persistence schema, project network protocol, or old numeric-ID compatibility;
- no bulk import of the upstream asset tree and no Minecraft/Forge art copies.

Save/network impact: none. This version adds inert registered content and data
resources only. Worlds remain disposable under the pre-v0.5 compatibility
policy. Provenance impact: ten transformed/copied upstream MIT inputs are the
maximum planned import batch; every target must be hash-bound before packaging.
