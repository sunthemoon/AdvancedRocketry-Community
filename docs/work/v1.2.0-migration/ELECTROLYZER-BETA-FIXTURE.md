## Implementation and limits

- `scripts/v120_electrolyzer_world_fixture.py`: fixed-entry extraction and a
  standalone semantic/hash verifier; refuses existing output and linked paths.
- `scripts/v120_precision_world_fixture.py`: shared Anvil helper now rejects a
  region header shorter than 8,192 bytes with `FixtureError`, rather than an
  uncaught index error.
- `tests/test_v120_electrolyzer_world_fixture.py`: ten tests for exact extraction,
  overwrite refusal, altered source/chunks/metadata, rehashed resource/data-version
  corruption, duplicate identities, already-migrated input, links, short headers
  and trailing compressed data. Two semantic cases use a decoded-object mock;
  resource and data-version corruption are exercised on real rehashed NBT bytes.

Input limits remain 16 MiB for ZIP/region, 256 archive entries, 128 KiB compressed
chunk and 1 MiB expanded chunk, with existing bounded NBT depth/tag/collection
checks. This semantic reader erases numeric NBT tag widths; it is not a substitute
for the Java runtime codec's strict schema-type tests. Archived regions are
closed snapshots, not live-region readback.
