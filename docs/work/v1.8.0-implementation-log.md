# v1.8.0 implementation log

## Goal and scope

Deliver [Classic Content Completion](../versions/V1.8.0-CLASSIC-CONTENT-COMPLETION.md):
restore the classic machines, materials, items, armor, components, recipes,
models, sounds and progression in source batches, with provenance, hashes,
licenses and conversion records for every imported file, until the porting
matrix has no `UNKNOWN` and no in-scope `MISSING`. Development evidence does not
approve a release or remove inherited Required Gates.

```yaml
version: v1.8.0
status: IN_PROGRESS
phase: IMPLEMENTING
execution_state: ACTIVE
branch: codex/v1.8.0-classic-content
accepted_development_baseline: 55da6a58842762c382edce0a5a842d06bb76ff6e
runtime_implementation_allowed: true     # ADR-060..063 ACCEPTED on 2026-10-03; each later batch ADR first
runtime_build: 1.20.1-1.7.0-dev          # unchanged in C14
last_updated: 2026-10-03
```

The v1.7 handoff is a development baseline, not a passed prerequisite. ADR-060
must separately authorize this version before any runtime change. Root is the
sole tracked writer. Independent review uses read-only repository access and
fresh Temp outputs. The untracked user documentation bundle stays excluded from
reads and writes. No upstream code or asset is imported in C14.
