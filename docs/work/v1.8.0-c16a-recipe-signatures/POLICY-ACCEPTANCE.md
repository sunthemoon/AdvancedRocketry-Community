Date: 2026-10-03. ADR-064 revision 4 accepts the owner-selected no-automatic-
migration policy after [independent proposal review](reviews/LEGACY-POLICY-REVIEW-02.md)
has no open Critical/High/Medium findings. Authority is the recorded
[owner decision](OWNER-DECISIONS.md) and conditional authorization, not a Gate.

the decision does not authorize a builtin-ID/resolved-hash compatibility guess,
resource loss or a new provenance-witness framework. Supported new JSON jobs
remain available. The author source correction, removal protection, current
pending-journal recovery and native restart preservation are separate review
and test scopes. No hatch/facade API or whole-version completion is admitted.
