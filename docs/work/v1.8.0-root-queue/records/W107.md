pre-admission terrain priming fixture: observe a normal save of the unchanged
5,000 mB tank before opening the loader gate. No post-admission save is suppressed
or inserted, and the native store order and cooldown remain unchanged. Its oracle
requires DESTINATION first and the specified tank/bank 5,000/1,000 snapshot; a
SOURCE-first store is not substituted as passing coverage. C1 additionally logs
normal terrain captures but retains its original checkpoint and strict durable
unequal-prefix oracle. If no existing save can persist that prefix, it remains a
coverage finding, not a change to the save order.

fault selectors may be reused; no new failure injection is permitted. All native
cuts require a forced stop and two restarts, raw quantities, markers and epochs,
and committed source/JAR/hook pins. Heavy runs require W107's own machine lock and
more than 10 GiB on both drives, with cleanup and lock release between cuts.
