Implementer: a headless Claude session in `D:/GitHub/arce-v180-w52f-import-root`, on the local-only branch
`codex/v1.8.0-w52f-import-root`. Root's `build.gradle` commit `c5648a21` (the `srcDir 'src/imported/v1.8/resources'`

## Result

The v1.8 importer now writes to `src/imported/v1.8/resources/`, and the six K6 icons live there with unchanged
bytes. The v0.1.0 asset baseline passes again. Both JARs ship each icon exactly once, the unit suite and all
1,068 GameTests pass, and the importer's `verify` reproduces K6 byte for byte.

**One item is blocked on Root:** `runData` fails on the committed `build.gradle`. The data run's `--existing` list
(lines 101 to 115) does not include the new root, so the K6 item-model provider cannot find its textures:
`IllegalArgumentException: Texture advancedrocketrycommunity:item/laser_lens does not exist in any known resource
pack`. Root needs to add `'--existing', file('src/imported/v1.8/resources/'),` to that list. I checked the fix
without editing `build.gradle`: a Gradle init script that adds only this argument
(`existing-import-root.init.gradle` in the evidence folder) made `runData` pass in 31 seconds, and the tree stayed
clean. Hosted CI's `runData` and `git diff --exit-code` step will fail until the line is added.
