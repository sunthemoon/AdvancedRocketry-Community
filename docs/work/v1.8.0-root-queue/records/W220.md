Null creation is excluded for the supported vanilla-enabled world and the
unchanged registered factory, not counted as a native pass. The installed

when its required features are disabled or its factory returns null. The

The new factory regression pins the registration and required features,
including the disabled-feature negative control. Replacing that factory or
disabling vanilla features in an already running fixture would manufacture
a different product, so neither is done. Exceptions are not null returns.
