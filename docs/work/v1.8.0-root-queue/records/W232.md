## Diagnosis and design

The unchanged screen reproduced `CLEAR: 201, SUSPECT: 1`. Its best match for the original
top was `1.12.2:assets/minecraft/textures/particle/footprint.png`, with `method: scaled`,
`scale: 2`, `iou: 1.0`, `rank: 0.7525`, `overlap: 0.0`, and `colours: 0`.
The footprint is an opaque 8x8 three-grey bevelled square, not a foot-shaped sprite.
Sampling the original 16x16 top at every second pixel drops its upper and left inset
border but retains its lower and right border. The dark exterior, intermediate diamond,
and bright surviving border consequently correlate with the footprint's dark top/left,
grey centre and white bottom/right. There is a real coarse tonal/frame resemblance in
that sampled representation, but the flag is a low-detail rank-measure false positive
for derivation, not shared pixel art or a copied diamond. Neither file shares an exact colour.

The replacement is an original recessed charging coupling, three-bar manifold and
connecting hose on a four-bolt plate. It keeps the existing tint, encoder and side
texture. Its equivalent footprint comparison is `rank: 0.6640`, below the unchanged
`0.75` SUSPECT threshold. The code reads no input bitmap. Vanilla files are used only
by the separate verification screen, and no vanilla artwork is committed.

The provenance record appends revision 1 dated 2026-11-01, including the complete grid,
183-byte target and SHA-256 `d421386f4e63eae8ad899a9826b96762819f6d4a25d312c3c67793c9e816bf7b`.
It explicitly supersedes the original top hash, retains both original entries unchanged,
preserves the original review block in `review_history`, and refreshes the pending
review digest. Human originality/license review and true-client visual acceptance
remain `PENDING_HUMAN_REVIEW`; this screen is not an approval.

The implementation, generated texture, test and provenance revision are committed locally
as `ce3c24ddffad580cacb45793a5ece55df91a0c42` (`fix(art): redraw gas charge pad top for vanilla screen`).
