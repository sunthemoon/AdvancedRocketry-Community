### Remaining native fixture design

E3 uses 256 fixed, disposable terrain-region fixtures. After their normal stores
and force complete, the gated hook closes only the oldest seeded FileChannel
immediately before the cargo terrain store. Vanilla's unchanged cache eviction
must propagate that close failure to the retained own-store future; the barrier
must retain L1. Exactly that native store error is expected. This observes the
propagated E3 branch only: unrelated, unobservable eviction/close failures remain
excluded diagnostic residuals, not durability guarantees. No writer decorator,
Mixin, proof rule or production fault path is added. E5 reuses the three-failure
retained-future seam in chunk 4,4; an independent real cargo component in chunk
5,5 must retire while the first becomes durably STALLED. Both restart with the
fault gate closed.

C-S3 seeds 255/256 neutral schema-2 composite floors using the existing counted
floor fixtures. A legacy named arrival exercises one reserved 256th key at 255,
and refusal at 256; named cargo's existing F1 hold is not bypassed. R2 first
completes real cargo, then adds the existing stale PREPARED transfer fixture and
its duplicate, requiring the normal recovery service to report FLOOR_CONFLICT.
The separate fixture propulsion bank is recorded but is not cargo accounting.
R3 moves the cursor's valid native tank block, changes the device fluid identity,
or relocates the exact device/root in the stopped disposable copy using the
existing typed Anvil helpers. The relocation retains original bytes and a hash
manifest. None of these fixtures alters production recovery or rewrites an oracle
after observing a result. G1 saves future/invalid bounded roots and compares them
exactly after both restarts. G3 sends the normal stop command at staged L1 or
UNKNOWN L2, then force-kills at the shutdown-entry hook before the drain; it does
not claim a completed graceful shutdown.

The runner still stops before the next cut after a contradiction. It also retains
available raw state and attempts both restarts when a native observation fails.
All new fixture selectors have hooks-off/exact-case tests. No admission, saved
schema, performance budget, timeout, status file or ledger policy is changed.
