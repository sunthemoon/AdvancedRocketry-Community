## Design choices

The fixed ADR numbers are 50 blocks, 20 native player ticks, five full cooldown
ticks and 512 durability. No matching numeric configuration exists; the existing
`equipment.classicEnabled` switch is reused. A zero-hardness block needs one tick.
All block entities are conservatively unsupported. Main-hand use is required
because the ordinary `ServerPlayerGameMode` harvest path reads that actual tool.
The gun uses real diamond pickaxe qualification, not unconditional harvesting.

Work resets on identity, Level, target/state, invalid ray or use-start/end changes.
Cooldown survives release/re-use and target changes, and also throttles refused
effect attempts. Trace work is bounded to 160 cells and 256 entity visits; hitting
the entity budget refuses the trace. The service holds at most one state per real
connected player and clears at logout and server stop. No custom saved root exists.

Breaking uses ADR-054 loaded/bounds/zone/station/spawn checks and the cancellable
extension event with the stable gun ID, then the actual server-player destruction
method. Its post-BreakEvent item hook revalidates before removal. Wear is applied
only after observed successful removal, including zero-hardness blocks. Vanilla
creative and enchantment durability rules still apply. Native loot and XP remain
authoritative. Entity hits attempt one player-attack damage point after area,
interaction, loaded line-of-sight and PvP checks; even refused hits occlude blocks.

The ledger and recipe manifest specify no laser-gun recipe. The NEW shaped recipe
uses three steel plates, two iron rods, one diamond and one basic circuit plate.
It is not claimed as legacy recipe parity. No upstream code or art was copied.
