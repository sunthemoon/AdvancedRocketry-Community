## Files changed by area and design decisions

- In `client/compat/jei`, `ArceJeiPlugin.java` delegates information registration to
  `OperationInformation.java`. The latter exposes a JEI-independent model/callback;
  only the existing optional plugin bridges to JEI's ingredient-information API.
  No process recipes, categories or optional-dependency declarations were fabricated or changed.
- The two language files are under
  `src/main/resources/assets/advancedrocketrycommunity_jei_operations/lang/`.
  This independent resource namespace prevents generated-language overwrites without
  changing data generators, build files or historical outputs. Translation keys retain
  the normal mod prefix.
- Numeric arguments use production constants/decisions. Examples include coal's current
  Forge furnace credit of 64,000 FE at 40 FE/tick, 1,000-unit canisters, the vent's
  20 FE/tick upkeep, builder costs and ground-research durations/credit. Configurable
  endgame values are explicitly described as defaults; live server catalogs remain authoritative.
  Black-hole fuel durations and output are explained as table/profile values, not falsely
  fixed values for every singularity. No ADR decision was changed.
- The new `OperationInformationTest.java` contains seven tests: absent-JEI execution;
  the actual plugin registration bridge using compile-only API jars and a proxy, without
  the JEI implementation; packaged bilingual keys/placeholders; executable combustion
  credit; finite gas and paid vent supply; assembly/research/endgame quotes; and exact
  census/table coverage with a registered page for each information-classified device.
- Documentation changes are the applicability table and this record. No upstream files
  or assets were copied, so there is no new upstream provenance batch.
