### Choices where the design left room

1. *"Prefix classification" of the composite in O2.* Settlement never forces the operation's AFTER state, so the
   composite classification is not a settlement gate. O2 recomputes the composite from the same decode and requires
   it to equal the composite of the frozen choice; the composite is never compared with a fuel-vector string or
   inverted. The ordinary path keeps classifying by the composite.
2. *R39 placement.* The check runs before normalization too (conservative: no native settlement action on a member
   whose Fluid is unavailable), for fluid cargo only; the hold is automatic (`OTHER_STATE`, not operator-retryable)
   and is rechecked on the existing 200-tick settlement retry.
3. *Device pruning authority* uses the coordinator's acknowledged ledger identity and operational state, stricter
   than the loader branch's `() -> true`.
4. *The veto* in A1 is a placement change of the chosen neutral survivor between O1 and normalization; any other
   difference holds the same way.
5. *P1-F8.* A landed rocket that still has its COMMITTED record gets transfer-guarded (named) cargo, which stays
   PREPARED behind the F1 fence (R48's D4; W124 pins it). The exactly-once case therefore runs on the merged P1-F8 code
   with a governed successor whose record F8 already removed, so the disassembly takes the plain path. P1-F8's three
   crash windows with cargo remain C-S5 native cuts.
6. *Terminal ARMED authority* is decided against a ledger value that holds the HANDED_OFF entry; it is not written
   into the live isolated ledger.
