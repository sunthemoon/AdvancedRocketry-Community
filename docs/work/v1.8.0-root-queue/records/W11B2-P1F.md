# W11b2 part 1 fixes

## Design before implementation

Date: 2026-10-14. Root is Claude; this is the assigned local implementer worktree.
The write scope is the five TASK findings, rocket/journal guards and continuations,
their regression tests, log expectations if needed, and this record. The shared
baseline was merged separately before these changes. No other agent is launched.

F1 compares scalar capacity, amount and committed debits whenever either fuel
state is legacy; native-to-native comparisons retain the complete resource
signature. A representation change is also a resource change. Legacy fuel cannot
receive escrow credits or markers: escrow endpoints require native propulsion,
so supporting scalar updates does not bypass a credited-resource guard.

F2 separates ledger protection from journal durability. Mount/movement events,
kill and live data replacement consult only escrow records, markers, tombstones
or a bound section; dismount events are never cancelled by this interlock.
Board and explicit leave wait only if this rocket's record/removal differs from
the last acknowledged journal snapshot, not for another rocket's generation.
A blocked journal still allows boarding/leaving but refuses launch and fuel
mutation. Refuelling waits for this rocket's own acknowledged authority and the
existing stationary/settled checks. Launch and cancellation still publish their
dependent effects only after an exact checked acknowledgement, including their
own replacement/removal. R1's whole-journal continuation and live-flight barriers
remain unchanged; F3's scheduling redesign is outside this task.

F5 forces the parent directory after replacement and after successful candidate
readback. F6 publishes UNKNOWN after an Error on the writer thread and retains
bounded retries. F7 gives journal continuations an explicit discard callback and
finishes pending player request entries on stop, identity replacement, authority
refusal or an exception; uncertain journal authority itself is not discarded.

No production admission, O2-O4 settlement, O-veto, ADR, risk register, status,
ledger, build script, workflow, asset or language change is planned. The optional
historical-world native crash cut is not included; decoded historical compounds
will exercise legacy gameplay in GameTests, not claim S2 migration acceptance.
