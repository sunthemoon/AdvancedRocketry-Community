### Choices where the decisions left room

- **Creation baseline.** M3's cut list implies a write before L1. The note makes it an empty-root checked
  write at writer generation 1, so that every later step is the existing-ledger path that W11b1 and
  W11b2 already cut. A failed readback when the new coordinator binds counts as a definite failure.
- **`PREPARING`.** A new status member, because `ESCROW_PENDING` must not say "no fuel moved" and
  `TRANSFERRING` would be wrong before apply.
- **`prepareFill` in two parts.** A pure check against a given root and an owner-thread admission, so that
  the first fill can check a virtual empty root before any coordinator exists and nothing fallible runs
  between `tryReserve` and the queue entry.
- **Ledger replacement.** The test-hook method refuses while the old coordinator holds queued, captured or
  UNKNOWN work; existing direct `DimensionDataStorage` swaps and `forTests` move to it.
- **Chained fills.** `RocketEscrowGate.idle` is false while a chain's markers exist, so for a
  same-direction chain the coordinator's prefix check replaces the idle test; nothing else is relaxed.
- **Unclaimed devices.** Breaking one drops an ownerless carrier. Ownership therefore follows the item for
  non-operators, and no non-operator placement can create a device owned by someone else.
- **Menu.** Owner only, with no operator bypass, matching the binding rule.
- **Fluid display.** Two container-data slots carry the session's numeric Fluid registry ID; it is display
  only and is never saved or sent back.
- **Estimates.** (starts x 20 s + 15 minutes + any GameTest run) x 1.5, from the measured W11b2 native
  runs (continuation 11: 33 starts in 10.5 minutes; continuation 15: 15 starts in 5 minutes).
