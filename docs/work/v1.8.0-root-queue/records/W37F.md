# W37F: review fixes

## Design (written before the fixes, 2026-10-14)

This worker owns the sleep/respawn service, its small backup codec, related tests,
the ServerPlayer access-transformer entries, the atmosphere completed-chunk check,
and this record. The task-authorized inbound merge is separate. No status, ledger,
ADR, risk-register, build-script, shared-worktree or other worker changes are made.

The death boundary is the connected logical-server player's END tick while dead,
including after KILLED removal. Every decision rereads options and destination
facts; a refused point is set aside and an accepted pending point is restored.
The existing DISCARDED leave event remains the final check before native reads,
including immediate death respawn and a mod's respawn(player, true) on a living
player. No Mixin is added. Native End credits exit is explicitly excluded as a
non-death dimension return: changeDimension removes with CHANGED_DIMENSION before
setting wonGame, and handleClientCommand calls respawn(player, true), not the
death branch. It retains native behavior. A mod respawning an already-removed
living player has no supported pre-read Forge boundary and is outside this check.

The exact dimension, position, angle and forced flag are written to a schema-1
root in Player.PERSISTED_NBT_TAG before clearing. The codec uses exact types,
bounded NBT preflight and finite native-coordinate/ID bounds. Clear and restore
write the four native fields through the existing AT, never the cancellable
setter. Restore verifies all four fields before deleting the root. The respawn
event, login and subsequent living ticks retry restoration; dead ticks instead
reevaluate the stored point and keep a refused point aside. No tick-end or stop
cleanup discards pending recovery. Unsupported/corrupt roots remain verbatim and
inert, without a repeated diagnostic. The implementation will explicitly report
any preservation limitation rather than claiming recovery of unreadable data.

Risk text proposed for Root: scope is one player's saved respawn tuple, not a
chunk or Level. A valid backup lasts until verified restore, including across
logout, player save/load, respawn and service restart. An unreadable/future root
lasts indefinitely until offline repair or a compatible reader is installed.
There is no save refusal, no exception used for save control, and no retry-log
spam. Back up the player's .dat before repairing only the owned Forge persisted
root; restore its four fields with a compatible reader, then confirm native save
and reconnect readback. Independent persistence review remains required.

The same-tuple sleep token and artificial after-return cancellation test are
removed; sleep refusal remains. D1 outcome 3 and natural=true belong to W37b.
Sleep head/foot and provider BlockEntity reads require getChunkNow completion.
Tests cover native death/packet lifecycles, vetoing setters, interrupted event
dispatch, player-file reconnect, codec failures and loaded-only admission.

## Execution

The schema stores angle_bits as an exact integer, because native FloatTag
construction normalizes negative zero. An unsupported prior owned root remains
verbatim as the retained child of a temporary schema-1 envelope if a later native
tuple also needs protection. Only the eight newly written fields are decoded and
bounded (1 KiB, depth 2, nine nodes, 256-character dimension ID, native integer y,
horizontal +/-30,000,000, finite angle, boolean byte and stable outcome token).
The opaque child is not traversed, copied or interpreted. Verified completion
returns that same child to its original key; repeated decisions do not accumulate
envelopes. An unreadable root with no new tuple is left untouched indefinitely.
The global Forge PlayerPersisted parent is not overwritten if another mod has
made it non-compound; that invalid foreign-parent case is outside owned-backup
recovery. This needs independent review, not a claim of migration support.

The interrupted-respawn check exposed Forge's shared PlayerPersisted reference:
old and replacement players can share this root while the connection still owns
the old player. Restoration therefore retains a verified backup until the
connection adopts the replacement. A server END-tick retry also handles an
installed replacement whose connection still points at the old player. A
non-cancelling spawn-setter listener completes an already verified recovery before
a later legitimate setter replaces it; it never vetoes a bed or other setter.
An unencodable native tuple (nonfinite angle or out-of-bounds coordinates/ID) is
left unchanged with any unreadable backup, rather than throwing during a dead
tick. That exceptional tuple is outside this bounded preservation policy until
repaired; no save is refused.

## Not completed, risks and next action

D1 outcome 3 and `natural=true` remain W37b work. Other C18a rules, state files,
the ledger, ADRs and the risk register were not modified. Root must add the
proposed risk entry and arrange the independent persistence review. This record
supersedes W37's tick-local backup and cancellable-clear risk descriptions, but
does not edit that historical record or accept an ADR/Gate.

Native End credits return is intentionally excluded and can honor or load its
native saved destination; the test executes real End `changeDimension` followed
by the respawn packet. An already-removed living player's mod-called respawn is
also outside the supported pre-read boundary. A mod replacing the native tick or
respawn implementation can bypass these Forge boundaries. A foreign malformed
PlayerPersisted parent, an unencodable native tuple, and an unreadable owned root
need offline compatible repair; none is overwritten, truncated or discarded.
Opaque retained data is not newly bounded or copied. A throwing foreign listener
can still interrupt the native connection-replacement sequence: the point is
restored and retained, but this service does not repair arbitrary mod failures;
reconnect may be needed. Unknown backup roots have no repeated logs and remain
until repair or a compatible reader is installed.

No full clean build, packaged dedicated-server restart or real-client/GPU Gate
was run. Native logout/player-file reload is verified, not claimed as a complete
server-restart Gate. No upstream file or art was copied. Current-version Required
Gates are not all met, and no version or Gate is marked passed. Root's independent
review and the two imported gravity failures precede acceptance; the next content
slice is W37b within v1.8.0.
