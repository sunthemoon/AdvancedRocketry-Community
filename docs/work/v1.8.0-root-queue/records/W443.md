## Harness changes (`scripts/campaign_client/`)

- **Gates.** `require` repeats a readback command, never an input, and waits at most 300 seconds. The screen
  state is read from the pointer clip that GLFW sets while the game holds the pointer.
- **Foreground.** A session started without a console window (the owner's rule for detached launches) was
  refused `SetForegroundWindow`, so every input failed. The driver now tries the plain call, then the
  foreground thread's input queue, then one synthetic Alt tap. Only the Alt tap worked here, with a browser in front.
- **Shift.** GLFW polls the real state of the Shift keys and releases one it saw only in a message. Shift is
  now sent through the system input queue, pressed only with the window in front and always released.
  The Alt tap and Shift are the only desktop-wide inputs the driver sends; the README says so.
- **W430 finding 2:** a launch client may set `"pause_on_lost_focus": true`; the default stays false.
- **W430 finding 4:** the lock's `owner.txt` starts with `campaign-<run directory>` or `--lock-label`; the
  rounds here wrote `W443-p9-v2-dedicated-NN pid=...`.
- **W430 finding 5 (answered):** the README now says that fixture `{id, ops}` files go through the file drop.
- **W430 finding 3 (answered in `v2/USAGE.md`):** the operator clicks Proceed once on the experimental-settings screen.
- **W430 finding 6 (open):** WMI cannot start PowerShell on this PC; the runners stay Python.
- **W430 finding 1 (observation only):** in the final round the client logged `OpenAL initialized on device ...`
  and `Sound engine started`. I did not test audibility.

## Known risks

- The Alt tap and the system-queue Shift are desktop-wide. A session killed between a Shift press and its
  release would leave Shift down until the next physical press; the only such pair is in `core-rocket-assemble`,
  about 1.5 seconds long. The Alt tap can reach whichever window was in front.
- The screen gate depends on GLFW's pointer clip; a full-screen window on a single monitor is refused as
  undecidable, so the 1920 by 1080 full-screen requests need a second monitor or a check of that case first.
- Revision 2's requests need this branch's harness; the harness on the shared branch refuses the new actions.
