## Mutation check

After the 12 focused batches passed, the temporary mutation replaced only the
`invalidate()` call in `WarpControllerMenu.beforeAction` with a comment. With
`JAVA_TOOL_OPTIONS=-Dadvancedrocketrycommunity.gameTestBatches=station_controls_route_warning`,
`runGameTestServer` failed its one required test, as intended. The failing wire view
already had status `CONTROL_RATE_LIMITED`, but retained cost 8,000,000, cost class 2,
route flag 0 and a positive token. The new immediate `assertNoQuote` rejected it before
navigation. This demonstrates that the added subcase detects missing invalidation of
an actually displayed routeless quote, rather than merely preserving an absent quote.

The mutation was restored before the build and full regression. Production SHA-256
was identical before and after:

`git diff --exit-code -- src/main/java/io/github/sunthemoon/advancedrocketrycommunity/station/controller/WarpControllerMenu.java`
also passed. The mutant was never committed.
