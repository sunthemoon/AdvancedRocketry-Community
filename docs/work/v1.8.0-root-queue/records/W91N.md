## Hard criterion, defined before measurement

A sample is one `(server tick, logical rocket)` visit in the ordinary
`RocketTransferService.tick` live-transfer loop. At entry to `tickLive`, the
probe observes the exact record identity and `journal.actionable(logical)`.
The per-record step is dispatch of that same record through `tickLive`'s phase
switch to `tickSource`, `transferPassengers`, `removeSource`, `updatePhase`, or
`tickDestination`. A missed actionable dispatch is a visit with an actionable,
still-current ordinary record which returns before that switch. This is a
conservative superset of the requested due-work misses: it counts even visits
whose countdown/transit deadline is not yet due. It must be zero. A nonzero
value stops the timing run and is reported, not repaired by changing a predicate.

This definition tests cross-record dispatch exclusion, not whether each visit
must move an entity or write a generation. Countdown/transit deadlines, loaded
entity/chunk readiness, pad checks, Moon-election waits and continuation-owned
effects remain decisions inside the per-record step. Phase/mutation and
continuation events separately show actual work and acknowledgement latency.
No zero value is claimed if the probe hits a cap, loses observations or has no
ordinary visits. The independent reviewer must check this definition and its
observation sites against the code; it is not self-approval of the criterion.

The criterion also includes due-work misses *inside* the phase dispatch. Due
means the existing countdown deadline condition is true, ASCENT is visited,
the existing transit deadline condition is true, a DESTINATION_SPAWNED,
PASSENGERS_TRANSFERRED or SOURCE_REMOVED branch is visited, or DESCENT is
visited. Within that same tick/record there must be an observed entity update
or position step, a journal mutation, or an explicitly observed own-record
wait (destination entity/chunk unavailable, pad unavailable, or failed entity
creation). A shared continuation-capacity refusal is not an own-record wait.
The hard count is the union of pre-dispatch and due-work misses. A terminal
Moon descent still executes its position step; its election wait is not a
missed step. Observations use the existing branches, not recomputed deadlines.
