## Files changed by area and design choices

The power snapshot and service changes are in `FieldCellView.java` and
`ForceFieldService.java`. The lifecycle and drop changes are in
`ForceFieldProjectorBlockEntity.java`, `ForceFieldProjectorBlock.java` and
`ForceFieldBlock.java`. Native tests are in `ForceFieldPowerGameTests.java` and
`ForceFieldSaveGameTests.java`; unit tests are in `FieldCellViewTest.java`.
`scripts/gametest_expected_log.json` adds only the new diagnostic's exact
expectation. This record is the only documentation change.

Synthetic height-external cells do not consume world-read budget. In-height
reads retain the existing loaded-only adapter, 25-cell stencil and unchanged
64-cell tick cap. A small height/reader constructor isolates the same stock
signal query in unit tests without a Minecraft server. Unit tests now initialize
their own Minecraft bootstrap. Exceptions never become power-off decisions:
projection, retraction and claims wait for a later valid visit. Fatal errors are
not caught. Diagnostics omit exception messages and stack traces and truncate
the exception class name to 128 characters. The diagnostic suppression and drop
arming state are transient; no schema, public ID or serialized state changed.
No ADR decision, assertion, timeout or performance budget was relaxed.
