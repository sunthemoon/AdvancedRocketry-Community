## Design and files by area

- `datagen/V180StandInArt.java` draws thirteen original, deterministic 16 x 16
  images without input bitmaps. The rolling-machine front has two rollers and
  a sheet between them. The plain side has staggered service plates and no
  drawer handles. The four port panels use the existing hatch palette and
  input/output arrow convention; fluid uses a droplet and energy a bolt.
- `datagen/V180StandInArtData.java` writes the new textures and eleven model
  copies into v1.8 only. `BootstrapDataGenerators` registers it.
- `V180ClosureModels` changes only the precision assembler's side binding.
  Its runtime v1.8 front already uses W49's NEW assembly-arm drawing, not the
  crafting-table front still present in the frozen v1.2 model. That functional
  front is retained rather than redrawn unnecessarily.
- `V180EquipmentData` binds four separately named cylinder icons. The three
  canisters likewise receive separately named icons. Every cylinder has metal
  shading, rounded shoulders and a transverse valve. Oxygen is cyan and
  hydrogen coral; empty has no band. Pressure tiers have one through four
  bands with distinct shades.
- `src/generated/v1.8/resources` contains thirteen new PNGs and sixteen
  texture-only model bindings. Parents, texture keys, geometry, IDs, recipes,
  loot and behaviour are unchanged. The earlier pressure-tank PNGs remain
  byte-identical but are no longer bound by their item models.
- `docs/provenance/v1.8.0-w275-stand-in-art.json` names all 29 generated targets.
  It explicitly supersedes the earlier precision-assembler model hash without
  changing its old record or review. The new record remains
  `PENDING_HUMAN_REVIEW`.

No save schema, migration, network contract, registry identity or ADR decision
changed. No upstream art, including the excluded legacy pressure tanks, was
copied or used as a drawing input.
