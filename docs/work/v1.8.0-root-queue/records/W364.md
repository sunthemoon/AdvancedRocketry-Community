missing stable endpoint unknown rather than treating it as zero, and rejects a

captures only the cursor's tank, from the same immutable snapshots used by its
binding. Every key's proposed mutation and the complete prospective ledger fit
are checked before reservation. Queued account rows join their operations in the
same L1 candidate and survive an unresolved candidate until its final outcome.

Live reconciliation checks typed vectors before issuing permits. A checkpoint
freezes numeric observations with its endpoint frontiers. Stable readback derives
signatures and vectors from one native decode, with owner-thread confirmation.
Prefix normalization removes later applied deltas and projects earlier unapplied
deltas before comparing each member with its original baseline. Completion
requires both applications; the immutable per-key before/after comparisons and
numeric continuity imply zero residual. Native L2 rechecks that account and
removes the operation and row together. The model-only proof API cannot retire a
root-3 fluid operation. C8 remains marker-only, including a transient wait for
retired leading markers rather than an accounting REPAIR.

A numeric mismatch holds only its connected component with the sticky manual
`ACCOUNTING_MISMATCH` reason. `ARCE_ESCROW_ACCOUNTING_HELD` is a WARN once per live
operation, bounded by the unchanged 64-operation ledger ceiling. Acknowledgement
forgets only IDs no longer in the ledger. Legacy root-3 fluid records remain
version-derived `UNKNOWN_BASELINE`: no C2 permit or ordinary L2 is available.
Fresh admission into their component returns a distinct coordinator/menu outcome
before sequence, reservation, queue or writer changes. Binding/capture operation
copies preserve the baseline commitment.

Commit `cb0b51c12` removes the additional generic scheduler WARN for this new
reason. The 64-operation test captures both log prefixes, so each held operation
has exactly its one named WARN even when the scheduler reports the hold again.
An independent healthy native fuel component can still issue its C2 permit.

The shared bilingual provider adds the menu messages without changing historical
provider key sets. Menu ordinals retain their original order, with the new outcome

Commit `6ad287ad8` contains the language provider, its generated output and the
