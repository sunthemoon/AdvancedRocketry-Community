| Existing test | Unchanged timeout | One-retry arithmetic |
|---|---:|---|
| Joint terrain endpoints | 200 | P + 2W + R = P + 154; fits when P <= 46. W36 measured P = 18--37. |
| Exact terrain/entity frontiers | 200 | Concurrent independent proofs need P + 2W + R + one final tick = P + 155; fits when P <= 45, including W36's measured preparation range. |
