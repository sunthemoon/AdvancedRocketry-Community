## Changes and design choices

- `scripts/campaign_client/session.py` recognizes `Unknown or incomplete command`,
  `Incorrect argument for command`, and `<--[HERE]` before testing expected text.
  A `require` attempt stops on the first rejection, even when that line does not contain the expected
  text. Retries keep their existing count and interval. Exhaustion raises `PreconditionFailed` with
  the rejection line, including when a later attempt times out. `server` with `wait` and `expect_log`
  ignore rejection lines and can accept a later real reply within the original timeout.
- `scripts/campaign_client/processes.py` extracts the existing indexed wait loop into `wait_for_log`,
  with an optional per-line matcher. It preserves the deadline, 0.1-second polling interval, capture
  failure and process-exit checks, and first-match ordering. Live logs are snapshotted under their
  existing lock. Raw process waits and the `client_wait` operation keep ordinary substring matching.
- `tests/test_campaign_client_replies.py` adds 16 Linux-safe tests using an in-memory captured log,
  a fake clock, and temporary files for the attached-log case. They cover all three operations,
  dedicated and integrated sources, normal `say`, each rejection form, I07's exact header and echo,
  immediate failure without matching text, retries, later real replies, chronological ordering,
  request/attempt boundaries, unchanged timeout and session-deadline handling, and capture/exit errors.
- This record contains the read-only scan and its complete finding list.

The error forms were checked against existing console logs, not inferred from the TASK alone.
For example, `round-02/A14/evidence/server-console.log` line 198 is
`Incorrect argument for command`; `round-04/d05-s0-w479/evidence/server-console.log` line 229 is
`Unknown or incomplete command, see below for error`. Both precede cursor echoes. Startup function
parsing also uses `Incorrect argument for command at position 88: ...yte 1 run <--[HERE]` inside
exception lines; these are excluded too. No ADR choice, save schema, network protocol, asset,
timeout, retry count, or interval changed.

### Reproduction of the primary scan

The following Python was run from this worktree through `python -B -`. It only reads the five rounds.

```python
from pathlib import Path
from collections import Counter
import json, hashlib
from scripts.campaign_client.session import command_rejection
base = Path('D:/GitHub/ARCE-Task-Evidence/final-campaign/c8fa16e16/phase2')
for number in range(1, 6):
    root = base/f'round-{number:02}'
    counts = Counter()
    findings = []
    for path in sorted(root.rglob('results.jsonl')):
        counts['sessions'] += 1
        for n, raw in enumerate(path.read_text(encoding='utf-8-sig').splitlines(), 1):
            if not raw.strip():
                continue
            result = json.loads(raw)
            counts['requests'] += 1
            request = json.loads((path.parent/'requests'/result['request_file']).read_text(encoding='utf-8-sig'))
            for index, output in enumerate(result['outputs']):
                op = request['ops'][index]
                kind = op['op']
                if output.get('precondition') == 'MET':
                    assert kind == 'require'
                    counts['require_MET'] += 1
                    receipt = output['receipt']
                elif output.get('expectation') == 'MET':
                    assert kind == 'expect_log'
                    counts['expect_log_MET'] += 1
                    receipt = output['line']
                elif 'receipt' in output:
                    assert kind == 'server' and op.get('wait')
                    counts['server_wait_satisfied'] += 1
                    receipt = output['receipt']
                else:
                    continue
                if command_rejection(receipt):
                    findings.append({'file': path.relative_to(base).as_posix(), 'line': n, 'request': result['id'],
                                     'output_index': index, 'op': kind, 'receipt': receipt})
                    print('INPUT_SHA256', path.relative_to(base).as_posix(), hashlib.sha256(path.read_bytes()).hexdigest())
    print(root.name, dict(counts), 'findings', len(findings))
    for finding in findings:
        print(json.dumps(finding))
```

The cross-check used this read-only traversal over all `.json` and `.jsonl` files in the same five rounds:

```python
def visit(value, pointer=''):
    if isinstance(value, dict):
        for field in ('receipt', 'line'):
            text = value.get(field)
            if isinstance(text, str) and command_rejection(text) and (field == 'receipt' or value.get('expectation') == 'MET'):
                yield pointer+'/'+field, text
        for key, child in value.items():
            yield from visit(child, pointer+'/'+str(key))
    elif isinstance(value, list):
        for index, child in enumerate(value):
            yield from visit(child, pointer+'/'+str(index))

for number in range(1, 6):
    root = base/f'round-{number:02}'
    counts = Counter()
    for path in sorted(root.rglob('*')):
        if path.suffix not in ('.json', '.jsonl') or not path.is_file():
            continue
        counts['files'] += 1
        text = path.read_text(encoding='utf-8-sig')
        if not any(s in text for s in ('"receipt"', '"expectation"')):
            continue
        records = text.splitlines() if path.suffix == '.jsonl' else [text]
        for line, raw in enumerate(records, 1):
            if not raw.strip():
                continue
            for pointer, receipt in visit(json.loads(raw)):
                counts['findings'] += 1
                print(path.relative_to(base).as_posix(), 'line', line, pointer, receipt)
    print(root.name, dict(counts))
```
