## Reproduction and design decision

The observed mechanism is [W273](W273.md)'s framework-button defect. The hosted failure did not
record its items, so that historical item's identity cannot be independently recovered.
Against the unchanged registration behavior with diagnostic messages added, the unloaded
13-test selection passed. Under four-worker CPU load, directing water across the real framework
button also passed while its drop remained outside the original assertion region.

In the loaded forced-landing reproduction, the button was at `(241, -60, -2)` and its backing
remained a command block. Water created one stone-button item at server tick 1370. The recorded
creation stack includes `WaterFluid.beforeDestroyingBlock`, `FlowingFluid.spreadTo`,
`Block.dropResources`, and `Block.popResource`, not rocket code. Retaining that actual item inside
the original region, without creating a substitute item, failed only
`AdapterRegistrationGameTests.externalAdapterRetriesRejectedPendingDisassembly` at tick 1655:

```text
Disassembly dropped duplicate inventory items: [1 stone_button type=minecraft:stone_button count=1 at (243.50980050008167, -59.99949999997625, 1.5098005000816546) age=286]
```

The original region was `AABB[240.0, -61.0, 0.0] -> [247.0, -54.0, 7.0]`. No product-created
duplicate was observed. The remedy removes only the fixture's own stone button, after checking
its command-block backing, without generating a drop and before rocket operations. Fault,
registration, and component fixtures now share that helper. The matching forced reproduction
passes on the final source: the control position is air, the backing remains a command block,
and no button item is created.

Every existing zero-drop assertion retains its region, item coverage, and emptiness requirement.
Messages now report registry type, count, position, and age. No item filtering or new item cleanup
was added; W273's existing fault-fixture pre-operation cleanup remains unchanged. No ADR choice,
adapter API, production behavior, asset, provenance entry, persistence schema, or network protocol changed.
