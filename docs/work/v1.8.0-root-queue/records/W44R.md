## Key design choices

- D3 remains world-first with immutable winning participants. No new owner product decision is
  requested. Independent round 2 review and Root's ADR/risk updates still precede runtime.
- Every journal load requests the same checked writer's baseline, independently of dirty state or
  transfer count. No unconfirmed RAM seeds proof; missing confirmation never means EMPTY.
- Temporary source/progression waits recover through bounded retries, without an offline-repair
  verdict. Permanent rollback requires validated known EMPTY versus an occurred receipt.
- Deferred grants use connection-instance identity and immutable receipt membership. The queue is
  capped at 4,112 entries, examines at most 16 entries per tick and retries each at most once per
  20 ticks; readiness work uses bounded one-time cursors. Disconnect removes only its own entries.
- Root-only station delivery validates unchanged stations/reservations/FE, exact event substitution
  and the clock, without requiring the winning station to survive. Shared extraction preserves
  named-transition gates and keeps each Java class within 800 lines; no second writer is proposed.
- R1 retains station outcome semantics and labels directory force best-effort in the
  error/readback-COMMITTED branch. Windows and inherited station in-place save limitations remain.
- The unreleased root-5 epoch migration uses an exact pre-CURRENT whitelist and unchanged root
  budget. Restoring old authority or downgrading requires a complete consistent world snapshot;
  managed-root migration backups and receipt-only revocation edits are not sufficient.
