## Design decisions and files changed

At original upstream pin `c5cd5af62fc07cd4e0d24f06a16033f181c47c04`, static source
inspection found a generated flat item model in every view, not a mesh-in-hand/flat-GUI
split. No legacy client run is claimed. R291's otherwise branch therefore uses the
mesh everywhere and excludes the unused upstream flat icon in the central-file draft.
No new loader is needed: the existing atlas walker already supports item-root
`forge:obj`; new fixtures retain rejection of unknown loaders and missing dependencies.

The imported names and `mtllib` are lowercase. Both `Diff` and `spec` retain their
identities through explicit identity mappings, and both diffuse maps point to the
stitched `block/basiclasergun` sprite. Geometry is unchanged. A root matrix normalizes
its bounds, accounting for Forge 47.4.10's `blockCenterToCorner()` conversion. Tests
parse the actual Forge transform and pin all eight display contexts. The four hand
transforms transcribe upstream's flat-model values; their mesh appearance needs V1.
The other display transforms and unflipped UV choice are documented modern choices.
