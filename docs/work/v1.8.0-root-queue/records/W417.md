## Tests and design decisions

Each batch contains one test, because the restart deliberately clears the endgame
runtime caches and reopens the shared service root between ticks.

| Finding | Batch | New test |
|---|---|---|
| F9 | `w417_logical_restart` | `f9LogicalJobRestoresSeedIndexEnergyAndExactNextOutput` |
| F9 and F10 | `w417_physical_restart` | `f9AndF10PhysicalJobAndActiveTargetResumeExactlyTheNextLayer` |
| F11 | `w417_black_hole_mid_burn` | `f11MidBurnRestartKeepsExactFuelCreditRateAndEnergy` |
| F11 | `w417_black_hole_full_buffer` | `f11FullBufferRestartPausesAndContinuesWithoutLosingBurnCredit` |

The tests first perform real work through server ticks. They serialize current
block-entity and EndgameSavedData roots through binary NBT, remove the old block
entities without destroying their blocks, construct fresh instances with
`BlockEntity.loadStatic`, and reconnect the event-bus-owned service to a newly
decoded SavedData root. The whole saved root is retained, including existing
endpoint records, instead of replacing it with an empty registry. Runtime
admission, budget, index and observation caches are cleared. These are A1
serialized/in-process restart cases, not native process-restart evidence.

The logical fixture configures seed 1 before starting, and requires its two live
Earth-table draws to have different items. It checks exact output inventories,
index, energy, lens and absent physical link before and after reopening, then
after the next draw. The physical fixture keeps the exact ACTIVE endpoint record,
both link identities and counters, seed, index, generation, layer and buffer.
Gold blocks placed in the completed layer detect replay; a dirt layer is the
next output, and an intact bedrock layer bounds further work. Physical mining
uses the existing `SwitchOverrides` opt-in and clears it after the batch.

The generator cases save a genuinely started stick burn, including fuel in two
slots, remaining credit, 500 FE/tick and exact buffered energy. They check ten
more burn ticks. The full-buffer case additionally checks twenty paused ticks,
extracts 5,000 FE through the real capability, verifies exactly ten replenishing
ticks, and checks another twenty paused ticks. Cleanup listeners release fixture
resources on success or failure.

These choices follow ADR-054, ADR-055 and ADR-057; no open ADR decision, product
contract, migration or provenance change was needed. The existing retired-copy
refusal test remains unchanged.
