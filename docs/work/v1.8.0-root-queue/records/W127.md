  separable and became W27d3 and W27d4.

  repair": every durable state a sub-leaf can create is resolved by its own code; anything else is refused at D0 or
  waits at runtime without a record change. It implies three interim behaviours, listed as Q4 for Root.
- **The registry benchmarks come first**, in W27d1, because the design's stop rule would otherwise fire after W27d2's
  registration code exists.
- **Placement** of the coordinator is a proposal that avoids a new package cycle; the implementer of W27d1 confirms it
  in its design note.
