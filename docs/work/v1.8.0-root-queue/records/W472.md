## Operator changes and design decisions

All changes are in `R/tools/`; the candidate and tracked harness are unchanged.

1. The queue fails closed on nonzero operator exit, non-COMPLETE summary, cleanup
   errors, retained lock, failed request count, request errors or absent results.
   Seven dry failure cases block the next row without starting Java. Live E06
   also demonstrates why the nonzero operator exit matters even when the harness
   has a COMPLETE lifecycle summary. Continuations were explicitly reviewed and
   given new queue files after failures; the original queues did not continue.
2. A12 uses six small field/count probes, never whole rocket NBT. The 64-block
   control returned **110, 117, 175, 130, 98 and 102 characters**; every reply was
   checked below 4,096 before larger scenes were admitted. The harness's
   **65,536-character bound was unchanged**. Exact block-count boundary probes,
   first/reloaded views and multi-rocket/close views are retained.
3. E04 reads K07's own Spawn ground `(0.5,-63,0.5)`, not K16's elevated platform.
   Successful copies explicitly preserve the source Normal difficulty. Exposure
   intervals are finite; recovery uses ordinary eating/regeneration; suits and
   canisters are ordinary interactions. Failed setup stops dependent actions.
   No health, oxygen, owner or device-resource NBT was injected.
4. Screenshot normalization covers the complete request-ID prefix as well as
   the scene name. Long names get a hash suffix within 80 characters. All retained
   native filenames pass the original protocol alphabet and uniqueness checks.
5. Typed Forge inventory probes use integer `Slot:4`, not player-inventory byte
   `Slot:4b`. Reload/reopen inputs explicitly dismount and use grounded aiming.
   No assertion, timeout, budget, test expectation or production code was relaxed.
6. Boot-time tool hashes and later content-addressed tool versions are retained.
   Early attempts have hashes/request maps but not every historical tool source
   archived. Later boot code pre-imports scene code before recording its manifest.
   Native requests/results, not a claim of perfectly immutable early operators,
   are the execution evidence.
7. Same-world restart archival, further API/research/audio cases, acknowledged
   HUD-config sampling and matrix operators were prepared but **never executed**.
   The restart hook's unit tests are not live persistence evidence. No API row,
   two-restart case, JEI cell, Chinese/scale/fullscreen matrix or human listening
   result is inferred from those scripts. No ADR/domain decision was changed.
