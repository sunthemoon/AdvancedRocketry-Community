## Choices where R55 left room

- A waived rocket (its captured propulsion requires no fuel) has fuel available for launch even at zero amount, so an
  `ASSEMBLED` waived rocket is launch-ready, exactly like a waived `LANDED` one and like `withFuel`'s own
  `FUEL_AVAILABLE` rule. Assembly cannot produce that shape: `RocketEntity` promotes a waived rocket to `FUELED` at once,
  so a waived rocket launches as before. The unit test covers both the assembled path and the restored shape.
- An empty `LANDED` rocket's legacy console quote now reports `INVALID_STATE` instead of the planner's code (for
  example `INSUFFICIENT_FUEL`). It could not launch either way, and catalog navigation already reported
  `INVALID_STATE`; the two now agree.
- `EscrowGovernedLaunch.planned` now refuses an empty `LANDED` source at its `require`
  (`IllegalArgumentException`) instead of in `withPlan` (`IllegalStateException`). No caller can reach that input: the
  launch gate refuses it first, and no PREPARED record can hold such a source.
- The ordinary gate promotes at the launch tick and `planned` at the checkpoint's own start time. `startCountdown`
  replaces both, so the encoded countdowns are equal; `assembledEscrowFilledSourceKeepsItsCheckpointStateUntilF2` uses
  two different times to prove it.
