## Design note (before implementation)

The assigned worktree is `D:/GitHub/arce-v180-w282`, branch `codex/v1.8.0-w282`,
starting at `be8c262df`. Write scope is the normal oxygen-canister use adapter,
its suit-service hand return, focused equipment tests, and this record. No asset,
ledger, status, queue, build, workflow, accepted ADR or other task file changes.
There is no push, merge or delegation.

ADR-066 sections 4 (W226 alternative), 5.1 and 9 D1, W174-DESIGN sections 2.4/9,
and W226's design distinguish normal oxygen use (active buffer) from sneaking
oxygen use (installed tank). The reported active 1,000 and EMPTY auxiliary zero
match that design. The balances remain separate; no oxygen migration is needed.

The persisted module `kind` is the shared `ModuleKind` family discriminator,
not the component's registry ID. All four tank items map to PRESSURE_TANK, whose
existing stable discriminator is `low_pressure_tank`. `stack.id` preserves the
actual tier and `TankData.maximum` its capacity snapshot. This is not a saved
pressure_tank item being converted into a low-pressure item. Preserve the stable
discriminator and test the four tiers and old data explicitly. No saved field,
schema, public ID, decoder or migration changes are planned.

W226 permits replacement of a single held canister in its source slot, and the
existing `CanisterStackSwap` already applies that convention to the finite tank
route. Apply it to normal survival oxygen use as well, in either hand. Keep the
existing stacked-canister inventory return and creative exemption unchanged.
The item adapter must return the actual post-use hand stack so vanilla item-use
publication cannot overwrite the replacement. This changes no persistence owner,
save policy, automatic charger behavior or cross-store durability claim.
