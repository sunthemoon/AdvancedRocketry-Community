## Files and design decisions

The write scope consists of the seven named screens; `AccretionDiscRenderer`, `LifeSupportHud`,
`RailgunBlockEntity`, and `JackhammerFeedback`; the client-only `BoundedTextLayout`, `ScreenText`,
`ScreenMessageState`, and `ScreenActionMessages` helpers; their tests and GameTests; the two v1.8
language JSON files and the corresponding entries in `V180LanguageProvider` and `V180SolarLanguage`;
and this record. No historical generated root, rocket/resourceescrow package, registry, build script,
status file, ledger, ADR or saved format was changed. No upstream asset or code was copied.

The fitting helper measures the ellipsis as part of the box width and does not split surrogate pairs.
It preserves trailing reason codes, scaling a code when it alone is too wide; the tooltip retains
the whole message. Styled text is measured again before drawing. The black-hole panel is 236 pixels
wide so its metrics have a separate 108-pixel column. Menu slots and server coordinates are unchanged.
The action-bar mirror does not cancel, rewrite or resend a server message. Its state is bounded to
one screen and one latest message. Jackhammer notification state is transient, weakly keyed by player,
and cleared on logout and server stop. There are no save, protocol or ADR changes.
