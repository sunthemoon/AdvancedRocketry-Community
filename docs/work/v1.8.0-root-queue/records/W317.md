# W317: warp controller per-orbit route warning

## Design before implementation (2026-11-07)

This implements [TASK W317](../TASK-W317-WARP-SCREEN-ROUTE-WARNING.md), Root decision
R368, on `codex/v1.8.0-w317`, starting from `ee0f6aa0a`. The assigned worktree was clean.
Other active workers use separate worktrees. The write scope is the warp menu and screen,
their classic-controls view contract and protocol pin, v1.8 language generation and its
outputs, related tests, and this record. No upstream files or assets are imported.

Append `TARGET_ORBIT_HAS_ROUTES` at index 7 of the warp view. Its exact integer range is
`-1..1`: `-1` means no displayed quote, `0` means the displayed quote's target orbit has no
route endpoint, and `1` means it has one. `WarpControllerMenu.viewValues` reads the existing
`displayed` quote, just as cost and cost class do. All three fields are assembled on the
server thread into one immutable `ClassicControlViewPacket`; there is no second route
query, capability inference, client route catalog or new cache. Navigation, failed requests
and closing already invalidate that quote. The flag describes the same quote as the price,
not an independent live route check, and does not change warp admission or confirmation.

`ClassicControlKind.WARP_CONTROLLER` changes from exactly seven to exactly eight values,
with the new scalar bounded to `-1..1`. The existing packet constructor and decoder enforce
that count and range before the client cache accepts a view. Old seven-value and malformed
flag frames are rejected. The screen requires both a displayed cost class and flag `0` to
show the warning; `-1` never produces a warning. Channel protocol changes from `2` to `3`,
including the test pin. Both sides of `ClassicControlsNetwork` use exact-version negotiation,
so a protocol-2 or absent peer cannot join a protocol-3 peer and misinterpret the new layout.
The outer packet schema remains 1: its envelope and encoding are unchanged, and the channel
version protects the kind-specific layout. The bound remains 8 KiB. There are no saved-field,
NBT-schema, registry-ID or persistence changes and no save refusal.

The screen uses the command's exact English warning, with a Chinese translation in v1.8
generated language resources. It occupies four wrapped rows immediately after the two cost
rows and before the countdown. Only the warp text starts higher, below its buttons; its
eleven text rows still end before the existing status area in the unchanged 256 by 222 panel.
Other controllers keep their existing layout. The warning uses warning colour and is absent
for a routed target or no quote. Confirm continues to require a complete price and positive
server token, and also requires the complete warning when present. Overflowing translations
therefore cannot hide a required warning while enabling confirmation.

Tests will cover real server views for Tau Ceti e, the Moon and invalidated/no quotes,
strict decode bounds and protocol mismatch, and bilingual cost/warning/countdown placement
with maximum-length body IDs and warning clipping. Verification includes existing warp and
controls tests, the full unit build, runData and a committed-tree diff, the full GameTest run
and log checker under the machine lock, and the strict repository validator. Root arranges
the independent read-only design/diff review before merge. Real-GPU visual acceptance is not
claimed. Routes, warp costs/rules, other controllers, the ledger, status files and QUEUE are
explicitly outside scope. No version or Gate is marked passed.

### Files and choices

- `WarpControllerMenu.java` appends the quote flag and includes the warning line only for
  a quoted, routeless orbit. `ClassicControlKind.java` bounds the eighth value, and
  `ClassicControlsNetwork.java` and `src/test/resources/network-protocols.txt` pin protocol 3.
- `StationControllerScreen.java` and `WarpControllerLayout.java` put the wrapped warning
  directly below cost, keep countdown and status separate, move the warp body tooltips to
  the same new text origin, and require full warning visibility before enabling Confirm.
  The other three controllers and the panel dimensions are unchanged.
- `V180StationControlData.java` and the v1.8 `en_us.json` and `zh_cn.json` add one translation
  key. The English wording is exactly the command's existing warning. The command itself
  is unchanged; sharing its literal English implementation was unnecessary.
- `WarpControllerRouteWarningGameTests.java` covers actual menu views, serialized through
  the view codec, for Tau Ceti e, the Moon, initial/no quote, navigation invalidation and a
  rate-limited request. It verifies price/class/flag consistency, warning placement in the
  component list, a positive quote token, and unchanged orbit, energy and countdown.
- `ClassicControlPacketsTest.java`, `NetworkProtocolPinTest.java`,
  `StationControllerLayoutTest.java` and `ClassicControlsChannelGameTests.java` cover strict
  flag bounds, old-frame rejection, the new protocol and bilingual layout. Golden bytes
  for the other controller views and all intents remain asserted. Existing malformed-frame,
  truncation, size, price-visibility and countdown-isolation assertions remain enforced.
- `scripts/gametest_expected_log.json` adds exactly two cleanup WARNs for
  `station_controls_route_warning`: its two test stations are deleted with their 9,000,000
  FE setup balances. The existing deletion warning is expected, not suppressed. The pinned
  ERROR total and the server-overload maximum of 8 are unchanged.

The conservative choices in the design were implemented as written: one appended tri-state
scalar, the existing packet envelope at schema 1 behind channel protocol 3, and a warning
snapshot tied to the displayed quote. There is no new route query, persistence field,
migration, route, asset import, admission rule or cost. The ADR, ledger, QUEUE, status files,
build scripts and other tasks' implementations were not edited.

## Not done, risks, gates and next action

Implementation and focused verification are complete. The full regression remains failed
as recorded above. Root's independent read-only review and hosted regression are pending;
this record does not approve any Gate or satisfy all v1.8 Required Gates. No status file,
ledger, QUEUE, ADR acceptance or version conclusion was changed.

No real-GPU V1, dual-client V2, new native-server/restart campaign or performance campaign
was run. No saved data changes were introduced. Layout tests estimate default-font widths;
they do not replace actual rendered-client evidence. Custom translations longer than the
reserved rows disable Confirm instead of allowing a hidden warning. The flag remains a
quote snapshot, just like its price, and is refreshed by requesting a new quote rather than
independently changing an already displayed quote after a route reload.

For V1 review, use a funded station and nearby loaded warp core, in English and Chinese at
the supported GUI scales. Request the Moon: price is visible without a route warning.
Request Tau Ceti e: the unchanged per-orbit warning appears below price, above countdown,
with Confirm enabled only after the complete quote is drawn. Navigate away or reopen the
menu: price and warning disappear. Capture the candidate commit/JAR hash, GUI scale and
screenshots; these steps are pending, not claimed results.

Root should review the design and actual commits, integrate the separately assigned W315
fixture fix, and use the hosted sharded regression to resolve the full-run and host-lag
results before acceptance. Rollback is a normal revert of W317's commits; clients and
servers must use the same resulting classic-controls protocol. No save migration or world
rollback is needed for this view-only change.
