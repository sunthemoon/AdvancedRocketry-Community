no production instrumentation or new ADR decision. Vanilla game-time queries
bracket asynchronous transitions; intervals are not wall-clock conversions.

server template is read-only; owned server copies are removed after each run.

The oracle therefore checks 255, 256 and 257, rather than pretending that
255 + 1 saturates it. Overflow chunks are outside each other's load halos.
Expected save errors are restricted to exact guard messages and the stopped
seed's generated-chunk allowlist. Individual vanilla tickets are removed and
their SavedData is checked empty before the restart-reset observation.

The downgrade fixture includes five claimed placed-device roots, actual bay
receipts and a schema-3 transfer journal, plus a valid empty schema-2 escrow
ledger. Its empty lists use native TAG_End encoding. W176's exact old JAR and
whole-world oracle are unchanged. Metadata changes remain a failed downgrade;
restoring only a store is not an accepted recovery operation.
