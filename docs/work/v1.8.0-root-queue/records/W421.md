## What was done

A new player guide, [docs/MACHINE-GUIDE.md](../../../MACHINE-GUIDE.md), has one section for each of the 38 devices
that [MACHINE-CENSUS](../../../releases/v1.8.0/MACHINE-CENSUS.md) section 3 marks as lacking player documentation,
and a pointer table for the 14 devices that already have a guide. The README has one new line linking to it. This
record, the guide and the README line are one commit; its SHA is in the final answer, because a commit cannot name
itself.

No code, test, language file or other document was changed. No JVM, Gradle, server or client was started.

## Sources and method

- Multiblock diagrams were generated by a script from the pattern files under
  `src/generated/v1.8/resources/data/advancedrocketrycommunity/machine_patterns/` and
  `src/main/resources/data/advancedrocketrycommunity/machine_patterns/`, not drawn by hand. The orientation rule
  comes from `PatternTransform` and the controllers' `transform` methods.
- Recipe tables come from the recipe files that the build packages. Three v1.2 files
  (`rolling_iron_bars`, `precision_control_circuit`, `precision_guidance_module`) are excluded in `build.gradle`
  in favour of their v1.8 copies, and the guide uses the v1.8 copies.
- Quoted messages come from the tracked `en_us.json` files. Values come from the constants in the code (for example
  `CombustionBurn`, `SolarGeneration`, `SolarArrayRules`, `PumpBudget`, `TankCapacity`, `AtmosphereLimits`,
  `GasChargeBounds`, `ResearchService`, `StationLimits`, `RocketLimits`).
- The JEI operation pages on branch `codex/v1.8.0-w419` were read as a map only. Where they and the code at this
  head differ, the guide follows the code: the planetary beacon has no energy input in its pattern or block entity,
  so the guide says it needs no power.

## Unclear from the code, stated conservatively or left out

These points were not settled by reading, so the guide avoids a firm claim. A real-client check would settle them.

1. **Rocket satellite bay.** `QUEUE.md` says the bay slices were merged "with new deployment admission disabled",
   and the README (last changed 2026-11-06) lists bay deployment as not yet available. I did not establish whether
   admission is enabled at this head. The guide describes the flow and says what
   "Satellite deployment is not available in this version." means.
2. **Gas charge pad and the README.** The README's "Not yet available to players" list says the gas charge pad
   waits for an owner decision. At this head the block, item and crafting recipe are registered and the census
   lists it, so the guide documents it. The README list also names the rocket loaders and the bay. It looks out of
   date, and it is outside this task's write scope.
3. **Station gravity range.** I did not find the limits of the gravity controller's value, so the guide gives only
   the step sizes.
4. **Ground survey product.** `ResearchService.start` creates an asteroid instance for the owner. The guide says
   only that analysis credits 120 research; how the instance is used afterwards is not described.
5. **Satellite builder and terminal.** Component rules come from the server's satellite definitions, which the
   guide does not list. The guide does not say how a terminal gets its owner; `setOwner` exists but I did not trace
   its caller.
6. **Force field.** The exact rule by which a projector's placement is refused (`FieldCleanupRoot.canAdmit`) and
   what stops the line at an occupied position were not traced. The guide says only that the server can refuse
   placement, and that the field does not enter protected areas or unloaded chunks.
7. **Suit workstation.** The module-to-piece table follows the module names in the language file and the W419 JEI
   text. The number of pressure-tank positions on the chestplate is not stated.
8. **Fluids in classic machines.** `removeController` empties the fluid banks without dropping anything, so the
   guide says fluids are lost when a classic controller is broken. What happens to the fluid of a single removed
   fluid hatch (its bank stays on the controller) is not described.
9. **Landing pad commands.** `/arcepad register`, `remove`, `list` and `select` are named from the command
   registration; the argument list of `select` is not given.
10. **Classic advancements guide.** It still says the crystallizer is "not in this build yet". The crystallizer is
    registered with two recipes at this head. That guide is outside this task's write scope.

## Known risks

- A guide of this size written from source can contain reading errors. The sections with the least certain details
  are those listed above.
- The guide quotes messages and values of the current head. Later changes to recipes, patterns or language files
  need a matching edit; nothing checks the guide against the code automatically.
