## Cause and design decisions

The fixture's two ends are in the same loaded Level: its source origin is
`helper.absolutePos(3, 2, 3)` and its destination is `helper.absolutePos(14, 2, 3)`.
The journal names the destination rocket at flight altitude over that destination.
The refusal observer incorrectly equated a destination UUID in RAM with publication
of the matching entity. `RocketTransferService.spawnDestination` writes
`DESTINATION_SPAWNED` first, then adds the entity in its journal-acknowledgement
callback. The consumed-package observer already recognizes this interval.

In the supplied hosted log, transfer `ded24e7f-882a-422b-af40-cd6759c4a987`
starts B14 at `18:03:54.830`, has an active TRANSIT source with 1,000 fuel, and
reaches `READY_SOURCE` at `18:03:54.931`. Its missing-destination assertion is
reported at `18:03:55.232`. There is no intervening destination publication or
relevant chunk-loading diagnostic. The source's earlier `DISCARDED` line is the
fixture's exception cleanup, not evidence that production discarded its authority.
The log alone does not expose the journal phase or prove a chunk-loading defect.

The refusal observer now continues its existing tick observer only when the named
entity is absent, the phase is exactly `DESTINATION_SPAWNED`, the source is live,
and the product's `journal.actionable(logical)` predicate is false. It checks both
journal snapshots and the live source's packages during this wait, then still
requires the matching published destination and its unchanged packages. An
acknowledged missing destination or an incorrect entity still fails. The 560-tick
wait bound, all original timeouts and batch assignments, and all 31 original
assertions are preserved; there are five additional assertions.

The regression waits for the product's destination-origin and full entity-column
readiness predicates, invokes the real installed service's `spawnDestination`,
and immediately observes its unacknowledged RAM phase in that same server tick.
It asserts the absent destination, live source, and non-actionable journal before
running the original observer. It changes no clock, writer result, production
queue, or readiness answer. With the original observer, exactly this new sibling
fails with the reported missing-destination assertion. With the fix, all seven
matrix tests pass, including eventual destination and package checks.
