Common to every machine test:
- Counting. Items, mB and FE are counted before (the stock put into hoppers, droppers, pumps and the budgets) and
  after (what is left in every container, port and bank, and every product collected). The assertion is exact
  equality: supplied = left + stated consumption, and produced = 20 × the stated output.
- Mid-run save and load. Once half the batches are done and a job is active, each test saves and loads the machine
  the way the existing restart GameTests do (`saveWithFullMetadata` then `load`, for the controller and every hatch or
  port; `ClassicLatheGameTests:203`, `RollingMachineGameTests:533`). It then checks that progress, stored FE and stored
  resources did not change.
- Refusals at the same point, on every face and the null side: an input that releases nothing, an output that
  accepts nothing, an energy input that releases no FE. Where the machine allows nothing to refuse, the test checks a
  mismatch instead: the tank refuses another fluid, the generator refuses a non-fuel item and any FE, an occupied
  scrubber refuses a second cartridge, and a seal refuses to forward into another seal. For the classic machines,
  the controller's full NBT must be identical before and after the refused calls.
- No duplication after the end: the machine and process tests run idle for 40 more sub-ticks (or three more game
  ticks) before the final count, and no loose item may lie in the area.

## 4. Choices where the TASK left something open

- **Where the tests run.** GameTests run near y = -59 inside the normal world's deepslate, and vanilla clears only a
  small box around each 1×1×1 `empty` template. Each test therefore opens an air room inside a one-block stone shell
  (`AutomationRig.room`), so no terrain or cave lava touches the fixture. The first filtered run failed on exactly
  this ("No hopper face").
- **Time budget.** Twenty batches take up to 24,000 machine ticks (the etcher). Each test runs several sub-ticks per
  game tick by calling the same static tickers the server calls: `HopperBlockEntity.pushItemsTick`, the dropper's block
  tick, the classic Level manager's `tick()`, a test-owned rolling or precision manager (as
  `PrecisionAssemblerMigrationSaveFailureGameTests.fixtureManager` does), and the generators' and electrolyzer's
  `serverTick`. Pumps and tank transfers keep one step a game tick, as they guard by game time, so the pump test needs
  over 100 game ticks (one drain per five) of its 300. Each test spreads its work over game ticks (1,000 classic
  sub-ticks a game tick at most), so no single tick is long, and all 18 finished inside their timeouts in every run
  below. The tests use one `onEachTick` each, registered at test start, and never register scheduled work from a
  callback; `GameTestSchedulingSourceTest` passes.
- **Power.** The classic machines are charged by a counted test source through the plugs' energy capability, the
  existing classic fixtures' source; their recipes need up to 9.6 million FE. The kernel machines, the pump and the
  pipe seal use the mod's combustion generator; the electrolyzer uses its own redstone charge.
- **Second faces.** Where a layout leaves the input hatch one free face (the arc furnace), the second side is a
  capability call on another face, which the hatch facade treats like any face. The droppers fire only while the
  machine is formed, so a dropper never throws an input into the world.
- **Fluids.** "A tank and the mod's pump": a pump cannot draw from a tank, so each fluid-fed machine gets a mod pump
  that the test tops up from a counted reservoir, and the pump pushes into the hatch or port itself. The tank test
  covers the tank with a pump feeding it.
- **Solar credit.** Sunlight has no input count, so the solar tests check each operation instead: every generator
  tick's published credit must equal what it added to its buffer plus what it pushed, and every pull must take exactly
  what it returns. The tests set noon and clear weather and restore them, as `SolarGeneratorGameTests` and
  `SolarArrayGameTests` do. They also require some credit, so a night or a roof cannot pass them vacuously.
