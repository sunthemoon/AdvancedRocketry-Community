| Terminal F7 request/capture and replacement lease | The source observer is the F7 passenger/prerequisite supplier, while `source.unchanged` is part of the off-thread replacement lease. | F1 source store/readback, queued ARMED capture and periodic observation | A refused observation currently releases the returned proof, clears the pending source and completes the attempt with null; the existing proof retry history is retained. ARMED capture checks the observer again. The write lease reads `unchanged`, and the after-ARM callback separately repeats the launch boundary before F2 publication. These checks must remain intact. |
| F4 source observation, absence callback and final publication | The adapter's source uses its final action boundary. The callback releases its result and proofs and removes the work when the source or boundary refuses. Later visits revalidate and reconstruct work under the existing retry/capacity checks. Final destination publication repeats both the boundary and source observation. |
| Pre-F2 cancellation | It constructs the source with the default always-true boundary. Its separate no-transfer lease, eligibility check, proof callback and existing cancellation backoff are unaffected by launch-boundary handling. Native mismatches remain sticky and cause release/recapture or refusal as before. |
| Diagnostic probes and detached GameTest/support captures | These also use the default always-true boundary, so there is no boundary-refusal behaviour to change. They still compare native fields and disk validators. |
