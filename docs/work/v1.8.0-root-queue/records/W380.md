## Sequence and key design decisions

The implemented positive sequence is a forced `FF_REBUILD_SOURCE` cut, two clean protected restarts,
a complete hash-verified backup, `plan`, `apply` to a fresh copy, and three separate clean
`FF_X03_OBSERVE` starts. A hash-verified descendant taken after the second observation runs
`FF_X03_UNLOAD`, `FF_X03_OBSERVE`, `FF_X03_LAUNCH` to MOON and `FF_X03_OBSERVE`. It is never the promoted
world. After the controls, the runner stages and renames a complete verified world, retains the original
and backup, and observes the replacement again. **The native runs did not reach plan acceptance, apply,
verification, the functional descendant, controls or replacement.**

The independent oracle requires 4,000 + 1,000 = 5,000 mB before the ordinary unload and
3,000 + 2,000 = 5,000 afterwards. It requires one physical rocket, one device, one snapshot tank payload,
no physical tank blocks, correct identities and epochs, no invented authority, and no fence after repair.
It reads the landed rocket from all on-disk Levels even when the source-area probe reports it absent.
The launch checks the physical Moon file and position and the actual primary-fuel debit, not only total fuel.

Only root-2, accounting-disabled development is implemented. Root-3 activation remains X03-C.
The before-witness describes the pinned fixture's 5,000/0 creation, not an inferred operator history.
Entity fields have no clock exemption. Terrain comparison exempts only `LastUpdate` and `InhabitedTime`;
all other typed entries, list elements and compound order are compared, including collateral objects in
listed files. File removal is always refused. A failed decode is not treated as absence.

The functional descendant has predeclared bounded source/Moon generation boxes and three named possible
managed writes: the ledger, station registry and classic progression. These allowances and the pinned
first Moon pad at (8, 8) remain **native-unverified**. Development measurement mode records contradictions
without converting them to accepted allowances and never promotes a world.
