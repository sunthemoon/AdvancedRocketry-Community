# W237: completion marker across a midnight log roll (R241)

## Scope and design

This implements [TASK W237](../TASK-W237-MARKER-MIDNIGHT-ROLL.md). The assigned
worktree was clean on `codex/v1.8.0-w237` at
`27c4d263ef773fa628b4c7f30ec9b130e7cb90e2`. The script and tests are committed as
`46211e7619ad9e2968269e1ca012c2d6a1eef18e`; verification uses an export of that
commit with the external Gradle patch applied. Root remains Claude.

The write scope is the checker, its completion regression tests, this record and
external W237 verification artifacts. No other worktree, build script, workflow,
status file, ledger, expectation, ceiling, upstream asset or game code changed.
No push, merge, rebase or delegation was performed.

- [The checker](../../../../scripts/check_gametest_log.py) exposes
  `--completion-only` through the existing `load_run` reader. There is no second
  rollover implementation. A refused reconstruction fails even if the remaining
  `latest.log` contains a marker.
- The completion mode retains the previous Gradle marker-only predicate for
  unsplit runs. It does not load the expectation manifest or replace the full
  log check's header, count, warning, error or shutdown validation.
- The external patch keeps the existing fresh-file check and its two-second
  filesystem timestamp allowance unchanged. It calls the Python completion mode
  and propagates a nonzero exit. A fresh startup-rolled predecessor cannot provide
  the marker of a new, crashed run. The optional `arcePythonExecutable` Gradle
  property selects an interpreter; the default is `python`.
- [Ten new tests](../../../../tests/test_check_gametest_completion.py) cover both
  midnight marker locations, fresh predecessor archives with and without shutdown,
  unsplit success/failure, missing markers, invalid gaps, missing/ambiguous parts,
  unreadable inputs and incompatible CLI modes. No existing assertion changed.

There were no open ADR choices, save/network/schema changes or provenance imports.
The original hosted job log was read and confirms the 23:59:58 success summary,
00:00:00 shutdown and subsequent old Gradle marker refusal.
