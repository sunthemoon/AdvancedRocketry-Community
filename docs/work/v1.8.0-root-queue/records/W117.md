### Design and coverage boundaries

Cargo kinds are independently false in production. The runtime-owned queue
retains a cargo continuation's reconstruction turn, preserves 256 slots/eight
visits/one fuel capture, and uses the unchanged session reconstruction budget.
First cargo creation shares fill's empty checked baseline. Successful operations
stop at acknowledged PREPARED, without publishing either endpoint's resources;
both endpoints stay locked and reconciliation returns
RECONCILIATION_UNIMPLEMENTED. Turn hints and active claims are RAM only.

The native test verifies load and unload, first-ledger creation, full-size
candidate fallback, closed switches, unchanged native endpoints, second/same and
opposite-direction cargo refusals, fuel refusal, next-token registration and
discard on unload. A0 verifies actual token handoff. **A1 does not demonstrate
later service of a competing device after a durable PREPARED operation**: no
hold is bypassed to simulate C-E2/C-E3. That requested native handoff coverage
remains unclaimed. Item devices, reconciliation, permits, settlement, pruning,
production enablement, native restart/visual release evidence and independent
review are not delivered by this slice.
