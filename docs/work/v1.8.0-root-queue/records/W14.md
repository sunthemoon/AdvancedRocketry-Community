# W14 life-support devices

## Implementation boundary and persistence design (2026-10-12)

This task owns the new atmosphere device classes, the oxygen vent integration and
schema migration, its tests and generated resources, and additive registration,
configuration, language and data-generator entries. It does not own status files,
the content ledger, build scripts, or other worktrees.

The vent is the sole persistence owner of scrubber cartridges and the debit phase.
It samples only six immediate loaded neighbours. Each scrubber has one unstackable
cartridge facade tied to a persisted device UUID and vent generation. Association
requires an adjacent cell in the same indexed sealed volume. One usable scrubber
skips alternating debits; two skip three of four, with one cartridge use spent per
skip. FE is still paid and the fourth oxygen debit is mandatory. Schema-1 vent
oxygen, FE, canister counts and oxygen phase migrate without numerical changes.
Unavailable owners refuse facade edits/removal; retained unsupported data refuses
ordinary destruction and uses the existing chunk admission guard when native
serialization would not preserve it.

Pipe seals own no resources. Their retained capability wrappers resolve one loaded
opposite neighbour per call, reject other pipe seals and reentrancy, and expire on
the seal's capability generation. Instruments reuse the analyzer's authoritative
cell/environment services rather than adding a second atmosphere truth store.

ADR-066 section 4 and D4 require demonstrated, independently reviewed player-file
save ordering before implementing automatic gas-pad charging. No such evidence
was found in this branch. W14 will not ship that runtime or silently substitute a
different interaction. Bounded pure transfer decisions can be tested without
claiming cross-store durability. The chemical reactor and lossless cartridge
refresh are not present in this checkout; refresh remains a follow-up. A new
cartridge recipe may create an initial cartridge but must not consume an existing
gas/resource-bearing cartridge.

## Conservative ADR choices

The proposed 32,766 uses and one-half/three-quarter schedules are used. A single
scrubber skips debit phases zero and two, and two or more skip zero, one and
two; phase three always pays oxygen. Each skip spends only one cartridge use,
and every active tick pays the original FE cost. Each of the six immediate
vent faces has at most one cartridge facade, so the six cartridge slots plus
the existing two vent canister slots stay within the eight-slot device limit.
Only the elected vent associates devices, using its indexed volume membership.
There is no room search, new pipe network or second atmosphere service.

Cartridges are normalized before admission so their first use cannot overflow
the owned item bounds. Existing canister counts, FE, oxygen and oxygen phase
migrate exactly. The scrubber phase and cartridge edits persist together in
the vent root. Unavailable/stale owners refuse edits and ordinary facade
removal. Loaded facades unbind when their vent is broken; an unloaded facade
does not trigger a chunk load or automatic reassignment. Foreign seal item and
fluid views expose at most eight slots/tanks. Foreign callback transactions are
not represented as crash atomic. Initial cartridge crafting uses iron plates
and a carbon brick, consumes no existing cartridge, and is not a refresh recipe.
