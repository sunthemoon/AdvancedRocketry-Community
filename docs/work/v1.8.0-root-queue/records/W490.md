## Method

- For each step I read its `original` text and, where the text was short, the row in
  `CAMPAIGN-CHECKLISTS-*.md`. The text after the separator is the oracle. For J13 step 1 the oracle is the
  Moon's sky, as R710 sets it.
- I read the machine readbacks of the step from the session `results.jsonl`, and the request file where the
  order of actions mattered, and say in each judgment whether they agree with the frames. No readback was rescored.
- I viewed 73 sheet pages for an overview and cite 167 distinct native frames. A cited frame was opened as the
  native file, or, for part of I07, as an unscaled or enlarged crop of the native file made by
  `J/tools/cropzoom.ps1` and `J/tools/montage.ps1`. The 18 crops are kept in `J/tools/aids/`. Rows that repeat
  one screen across display cells or states (E04, A16, J16, F07, I07) were sampled natively and read in full on
  the sheet pages.
- Both `VISUAL_FAIL` verdicts were confirmed on native frames. No verdict rests on a file name, a caption or a
  log line alone.
- I kept W482's rule for oracles with a part that cannot appear on screen (it is an interpretation, not part of
  the TASK): the verdict is `VISUAL_PASS` when the visible part is shown and an agreeing readback covers the
  rest, and `STILL_PENDING` when the oracle names something visible that no frame shows. Each such judgment says
  "Visual half only".
- None of the 62 steps asks for sound in its text, so no verdict has a sound half.
- For each step that W482 judged on round 04 or 05, the judgment says whether round 06 changes that verdict.
  [W485](W485.md) kept every W482 pass among these rows, so its verdicts are the same as W482's here. Root set
  B02 step 7 to `STILL_PENDING` after W482 (R704); that is noted in its judgment.
