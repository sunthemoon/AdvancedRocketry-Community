## Files and design decisions

Production changes are confined to the solar layout, controller, manager and the single generator's NBT permission override. Test changes are confined to `SolarArrayFixture`, `SolarArrayGameTests`, `SolarGeneratorGameTests` and `SolarArrayLayoutTest`. This record and its compact validation logs are the only documentation additions.

Panel claims are ephemeral, controller-owned, and limited to 63 positions. They use the existing footprint index rather than another world index. There is no persisted priority, schema change, migration, new configuration, network message, data generation or per-tick footprint scan. Simultaneously dirty arrays still use normal queue order; the holder's own dirty event no longer queues its newly awakened competitor first. The 66-cell evaluation and existing kernel budgets are unchanged.

The chunk tests exercise the registered handlers using native Forge events for already loaded chunks. They do not claim an actual disk unload/reload or a dedicated-server restart round trip.
