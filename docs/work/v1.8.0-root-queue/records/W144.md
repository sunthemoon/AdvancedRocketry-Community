### Native reference stage: partial evidence, then stop

The first attempt, `r83-reference-01`, failed during observer setup before any cargo
measurement: the reference created its ledger after Runtime's scheduler lookup.
Commit `d88d141caa00ddd072d78cd882453e575114f30b` makes the observer wait for the
ordinary scheduler to exist, adds bounded failure diagnostics and preserves missing
reference artifacts as explicit coverage gaps. It changes no product behavior or
pressure-stage implementation. The original failed evidence remains intact.

The second attempt, `r83-reference-02`, used that exact clean commit and reached:

- Eight real cargo devices, one large and one small per fluid/item load/unload kind,
  plus two real fuel loaders; the mixed queue contained ten requests.
- Four maximum-family rockets with 2,048 blocks and 128 payloads each. Native
  aggregate bytes were 951,360 (fluid load), 951,402 (fluid unload), and 951,449
  (both item cases). Whole snapshot sizes were 1,048,534 / 1,048,576 /
  1,048,576 / 1,048,576 bytes. Every adjacent aggregate byte was refused by the codec.
  These are codec-admitted fixture maxima, not a completed device-admission result.
- Initial tracked visual delivery for all eight cargo rockets.
- Real item load/unload fixtures with 355 flat byte-valued tag keys: inner stack and
  2,909-byte frame were valid, but both returned `CARGO_TOO_LARGE` without mutation
  after 4 and 8 ticks respectively.
- The existing reference workload started: two owned player connections, 16 oxygen
  providers, ten station records, 100 satellite tasks, eight governed flight requests,
  and a successful 2,048-block assembly reported by the product log.

It then stopped with an actual native collector failure. The stack trace names
`EscrowSettlementRecovery.java:94`, which emits `settlement.attempt` with value 0.
`EscrowFlightBenchmarkMetrics.java:34-35` permits only `[a-zA-Z0-9_]+` phase names
and throws `Invalid governed benchmark sample`. The dotted name, not the numeric
sample, is incompatible. The nearby dotted wait labels have the same incompatibility,
but `settlement.attempt` is the observed failing call.

No later native run was launched. The collector, its assertions, the emitted labels
and production sources were not changed. This diagnostic-mode failure must not be
described as an ordinary production-server crash.
