# W05: electric arc furnace and cutting machine

## Implementation design (2026-10-12)

The worktree started clean at `1377c1f8` on `codex/v1.8.0-w05-arc-cutting`.
The write scope is the two classic machine definitions, their registry and COMMON
sawmill setting, W05 generated data and original art, JEI/display registration,
targeted tests, and this record. Status files, the ledger, build configuration,
other machines and W01 removal/ownership rules are excluded. Other active workers
use separate worktrees. No delegation, push, merge or shared-tree edits are made.

Both machines reuse W01's controller checkpoint, resource banks, bounded recipe
lookup and kernel transactions. Their stable IDs are `arc_furnace` and
`cutting_machine`, with recipe types `arc_furnace` and `cutting`. Existing lathe
JSON/signatures and all checkpoint schemas remain unchanged. The bounded recipe
rows gain an explicit type and an optional cutting-only `sawmill` boolean, included
in the authored JSON signature. Turning the COMMON wood setting off prevents
lookup and pauses an active marked job before any energy or resource mutation;
turning it back on wakes lookup and preserves progress.

The arc furnace keeps the pinned parts, coordinates and dimensions. ADR-016
requires complete rectangular patterns and a closed matcher set with no ignored
cell. The conservative interpretation of ADR-064's unspecified null-cell handling
is to require air in the 20 legacy null positions. This is stricter clearance than
legacy and is explicitly a compatibility limitation, not a kernel-contract change.
An early uncommitted experiment with an `any` matcher was removed after checking
ADR-016; no matcher or lifecycle contract change is delivered. Wildcard cells use
a bounded block tag. The existing lifecycle coordinator already discovers
physical hatches in tagged cells; no new binding or ownership rule is needed.
New controllers reuse the existing save-size guard, including its known R-021
limitations; no new save refusal policy is introduced.

The pinned upstream commit is
`c5cd5af62fc07cd4e0d24f06a16033f181c47c04`. Layouts, times and counts are behavioral
facts only. No upstream source, bitmap or model is imported. Textures are original
deterministic integer drawings. Controller crafts will avoid requiring steel in
the first steel-production machine, so the new route can be reached in survival.

## Choices and sources

The legacy layouts were checked directly in
[TileElectricArcFurnace](https://raw.githubusercontent.com/Advanced-Rocketry/AdvancedRocketry/c5cd5af62fc07cd4e0d24f06a16033f181c47c04/src/main/java/zmaster587/advancedRocketry/tile/multiblock/machine/TileElectricArcFurnace.java)
and [TileCuttingMachine](https://raw.githubusercontent.com/Advanced-Rocketry/AdvancedRocketry/c5cd5af62fc07cd4e0d24f06a16033f181c47c04/src/main/java/zmaster587/advancedRocketry/tile/multiblock/machine/TileCuttingMachine.java).
The four authored arc recipe files `ingotsteel.json`, `siliconingot.json`,
`ingottitaniumaluminide.json`, `ingottitaniumiridium.json` and the three cutting
files `siliconwafer.json`, `basiccircuit.json`, `advbasiccircuit.json` were read in
the same pinned repository's `src/main/resources/assets/advancedrocketry/recipes/`.
The titanium mixed-material registration and its 100-tick, 10-FE numbers are in
[AdvancedRocketry.java](https://raw.githubusercontent.com/Advanced-Rocketry/AdvancedRocketry/c5cd5af62fc07cd4e0d24f06a16033f181c47c04/src/main/java/zmaster587/advancedRocketry/AdvancedRocketry.java).
The vanilla wood behavior was checked in
[RecipeHandler.java](https://raw.githubusercontent.com/Advanced-Rocketry/AdvancedRocketry/c5cd5af62fc07cd4e0d24f06a16033f181c47c04/src/main/java/zmaster587/advancedRocketry/util/RecipeHandler.java).

Modern rutile drops `raw_rutile`, unlike the old self-dropping ore. The titanium
ingredient therefore accepts the existing `forge:raw_materials/rutile` as well as
`forge:ores/rutile`, with the same one-ingot output and legacy time/FE. The wood
switch applies to every marked recipe, including lightwood, as ADR-064 specifies.
Unmarked wafers and circuits remain available when it is off. A loaded COMMON
change is observed by the Level manager on its next tick, including idle machines.
The first arc-furnace craft deliberately needs no steel or motor and no direct
circuit item; its casing can use the base's existing quartz/redstone wafer and
circuit crafts without either new machine.
The 20 legacy null cells require air, as explained in the design above. This
clearance difference needs Root's explicit integration judgment.
