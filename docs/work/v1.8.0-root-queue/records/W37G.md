cancel events or change scheduling. It has been removed; production source again

`build/w37g/diagnostic.patch`, not an accepted delivery snapshot.

The native path is verified against the mapped Forge 47.4.10 JAR using JDK
17.0.7 `javap -p -c`:

- `ServerPlayer.doCheckFallDamage`: offsets 0-4 call
  `touchingUnloadedChunk()` and jump directly to return at 48 when it is true.
  The superclass fall check is only called at 45. See
  `build/w37f/ServerPlayer-javap.txt`, lines 2386-2412.
- `Entity.touchingUnloadedChunk`: offsets 0-8 inflate the player's bounding box
  by one; 9-41 floor the minima and ceil the maxima; 43-64 negate
  `Level.hasChunksAt`. See `build/w37g/Entity-javap.txt`, lines 9093-9127.
- `LevelReader.hasChunksAt(int,int,int,int)` checks the inclusive chunk range.
  Here, `ceil(1198.5 + 0.3 + 1) = 1200`, so chunk z=75 is required even though
  the landing's center is in z=74. See
  `build/w37g/LevelReader-javap.txt`, lines 475-511.
- W38's `GravityFallFixtures.landing` loads only `level.getChunkAt(test)`.
  Its `serverFall` changes y only and repeatedly calls the guarded native
  method at the same x/z. Consequently all 41 calls are skipped, not canceled.
- `GameTestBatchRunner.createStructuresForBatch` retains the next structure
  corner across batches and advances it with structure sizes (offsets 131-209).
  W37's additional structures therefore change W38's absolute coordinates.
  See `build/w37g/GameTestBatchRunner-javap.txt`.

These facts explain why the unchanged W38 tests pass with another suite layout.
Changing W37's production sleep/respawn policy, reordering its tests, or leaving
unrelated Moon chunks loaded would mask the fixture dependency rather than fix
it. No W37 listener is suppressing these living players' fall events: the native
method returns before reaching the event path. The `death_respawn` batch, which
temporarily changes `doImmediateRespawn`, also starts after the gravity failures,
not before them.

TASK-W37G explicitly requires stopping before a W38 fixture change. This worker
therefore makes no production/test fix and adds no production regression test.
Root needs to assign a W38 fixture correction that prepares all chunks used by
the native fall admission check, without weakening expectations or timeouts.
The requested two passing native delivery runs remain uncompleted. No version
or Gate is marked passed.
