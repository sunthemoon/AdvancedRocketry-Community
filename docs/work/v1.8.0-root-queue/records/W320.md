## Temporary failure demonstration

After the implementation commit, each test temporarily added a notice summary and executed `helper.assertTrue(false, ...)`
immediately after installing its cleanup listener. The exact development-only change is `forced-failures.patch` in the
external evidence directory below. Both tests failed as injected, so Gradle and the completion checker correctly exited 1.

Both listeners logged `ARCE_GAMETEST_STATION_REMOVED`, with `waited=0`. The Flight Test Station removal reported
`template=289/289`; the Quote Probe reported `template=0/289`, because that test creates no platform. The saved registry
contained zero stations and reservations, and the seeded notice store was empty. There was no cleanup warning.

The temporary lines were removed using a reverse manual patch. `git diff --exit-code` then passed against the implementation
commit, and a source search found no probe text. The focused run, build and full run below used that clean, committed source.
