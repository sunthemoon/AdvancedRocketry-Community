### Observed source-format detail

The first real-source loader run rejected the lathe's 28 Rod faces: they
use `position//normal` while the same OBJ also defines UVs. Forge would read
UV index -1. The importer correctly accepts this legal source OBJ, but the
runtime's original strict parser check rejects it. The Rod is recipe-only
and is already omitted by the idle design. Source validation now permits
missing UVs only on the catalog's explicitly omitted parts, while still
validating their indices, syntax, materials and full face/position budgets.
The adapted bytes undergo the unchanged strict check before Forge. Direct
strict checks and visible untextured faces still fail; regression tests also
reject invalid indices inside omitted parts. No budget or existing assertion
is relaxed, and no arbitrary model gains this exemption.

The crystallizer has a quartz crucible directly above its controller. Its
fixture therefore samples light two blocks above, unlike the other models'
one-block sample. A pattern-level assertion checks that each K2 sample is
outside occupied cells. This changes neither geometry nor machine matching.
