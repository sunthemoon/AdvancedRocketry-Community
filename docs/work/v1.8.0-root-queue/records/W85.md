## Choices where the contract was open

These are proposals for Root and the read-only reviewer, not decisions.
- **Where D lives.** D is a section on the landed transfer record T in the existing checked journal (option A), not a
  new root (B) or a checked v0.5 journal (C). T and D then change in single generations of one writer, and only
  three durable states exist.
- **Format.** A D-carrying record is encoded as record schema 4, so every older jar refuses it and preserves the
  journal. A flag on schema 2 would not do this, because the schema-1/2 decoder ignores unknown keys. Root 3, the W44
  outbox and W11b2's record 3 are unchanged.
- **Release timing.** T is removed only after every restored chunk has a `ChunkDataEvent.Save` at least 40 ticks old
  (the ADR-051 section 5 signal with ADR-054's age rule). Without that gate, an arrival that was never saved is lost
  if the server stops before the next save, as it is today.
- **Ambiguous restart evidence.** No entity and no restored block at all holds the record for offline repair (row
  R5). The reconciler never rebuilds and never places a block.

### Choices where the contract was open

These are proposals for Root and the next read-only reviewer, not decisions.
- **Re-inserting T.** Root's direction assumed that the journal-backed geometry reservation could not be re-established
  without a new durable protocol. The existing `put` can re-establish it with the identical schema-2 record. This is
  safe after a clean failure, because no restored block can then exist on disk or in RAM. M uses it, so the
  reservation is lost only in the recorded residuals.
- **Named-pad claim.** Nothing needs to be re-established. The claim is released when the landing commits
  (`RocketTransferService.java:686-691`), and `LandingPadService.claim` (lines 86-99) treats a COMMITTED or absent
  transfer as stale.
- **The preflight.** The no-mutation checks of `RocketDisassemblyTransaction.execute` (lines 68-123) move into one
  read-only method that both the request and `execute` call, so the two cannot drift.
- **The 200-tick limit.** The continuation restores only within the confirmation token's lifetime; after that it
  re-inserts T.
- **W83.** The design recommends W83 as an admission prerequisite, because it protects a rocket in the residual cases.
  Root decides.
