### Hooks and ownership

One manager-owned service is created at ServerStartingEvent and cleared at stop.
It owns W239's single selector/budget, the live slots, endpoint hints and separate
UUID/T history. No static world collection, persisted field, packet or save root
is introduced. All operations require the installed server's owner thread.

The single Forge adapter observes EntityMountEvent (LOWEST, receiveCancelled),
PlayerTickEvent START/END, ServerTickEvent END, LivingFallEvent (LOWEST,
receiveCancelled), LivingAttackEvent (LOWEST, receiveCancelled),
EntityTeleportEvent, PlayerChangedDimensionEvent, PlayerLoggedOutEvent,
LivingDeathEvent and PlayerEvent.Clone. Mount observation never cancels detach.
A cancelled detach expires without history. The RocketEntity location hook uses
the captured permit after detach. Hook bypasses drain FIFO at the next END only
while the captured instance/position/generation still matches. The service performs
the one same-Level connection correction without a ticket; the location hook
returns that same selected position. Repeated callbacks reuse their result.

Existing menu validation/rate/replay admission precedes a small held-LEAVE
delegation. That operation calls stopRiding only for the actual rider. The old
ordinary LEAVE assignment-removal behavior remains outside a bay hold. Existing
release/rejoin guards take precedence. Checked anchors require the current T,
logical acknowledged digest/actionable lease, exact endpoint/hash/manifest and
the coordinator's current claim/receipt observation. Otherwise only local
candidates are available, with no fall capability.

### W230 revision rules

- **R1:** never cancel or alter LivingFallEvent. Observe first contact (including
  cancelled/zero damage), require ordinary loaded support, previous airborne
  descent, and exact remapped vanilla landing frames. Only a paired synchronous
  LivingAttackEvent with exact DamageTypes.FALL may consume/cancel once. Non-FALL,
  dripstone, direct hurt/causeFallDamage, unsupported paths, missing frames or
  exhausted 32-stack/64-frame allowance close the offer. No broad damage tag.
- **R2:** use one cached read-only `f_9767_` field resolved by Forge; observe the
  connection identity and local transition serial. Trusted moves revoke before
  any preflight/detach/teleport/mount and never restore in finally. Teleport intent
  invalidates even when cancelled. Only the exit's own exact single-increment
  correction establishes a baseline. Tick/callback samples enforce the stated
  finite, last-sample, per-tick movement/mode/radius/deadline limits. Uncertainty
  revokes rather than pausing. No reflective write, ASM or Access Transformer.
- **R3:** one instance-bound live slot/player, at most 1,024. Separate immutable
  first-exit UUID/T rows (1,024 rows, 64 T buckets), admitted only after actual
  authority-checked detach, including successful placement. Lifecycle cleanup
  drops live state only. No eviction; T-A/T-B/T-A retains both offers. History
  cleanup requires operational clean journal, absent current and acknowledged T,
  no pending effects and no live reference. Restart clears all RAM state.
- **R4:** reuse W239's single owner-thread selector, shared 128/4,096/256 counters,
  32/96/16 per-exit/candidate bounds, reservations, attempt/capture sequences and
  FIFO END drain. Contact probes share that allowance. Do not reset on callback,
  defer budget refusals, or claim scheduling-independent fairness.

### Design points recorded for Root

The conservative implementation uses only exact recorded endpoint hashes, rather
than expanding the recognition predicate; changed/ambiguous receipt or claim
observations downgrade to local-only before selection and revoke existing grants.
Unknown/custom contact blocks fail closed. Vanilla special landing overrides get
no safeguard unless they traverse the exact approved Block.fallOn frame chain.
Observer resolution failure is a bounded INFO diagnostic and disables grants.
These choices do not widen Q1, mount authority or the source-aware allowlist.
