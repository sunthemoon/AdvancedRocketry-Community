### R1 in detail

- The view carries a positive token for the quote the warp menu shows. The token is offered only
  while that exact quote is the holder's live, unexpired confirmation, so Confirm is inactive
  otherwise.
- A Confirm intent with no shown quote is refused as `WARP_NO_CONFIRMATION`, and one with another
  token as `CONFIRMATION_MISMATCH`. Otherwise the service's `take()` accepts only that exact issued
  quote, compared by identity rather than by value.
- Next or Previous, any new request (including a failed or rate-limited one), and closing or
  replacing the menu withdraw the quote the menu showed. After that, the menu and the command both
  find no confirmation. Another confirmation of the same actor is left alone.
- The command path keeps its one-shot, expiry and authority checks. A refusal before `take()`, such
  as R2's missing core, still consumes nothing.

### R3 in detail

`StationControllerHolder` checks, in order and stopping at the first failure: holder, connection,
alive and not a spectator, same Level, controller chunk loaded, exact block, reach, then the
operational registry's station at the controller is the one the menu was opened for, then VISIT
access. A menu that fails sends no view and ignores intents, and the player's tick closes it. A
former owner who stays a member keeps the view but can no longer manage.

## Choices where the ADR was open

- **Intent layout.** Schema byte 1, container ID 1..255, kind byte, action byte, value byte and
  token long: 13 bytes. Only the warp request carries a value (the target index the screen shows,
  at most 31) and only the warp confirmation a token. The per-kind action table and view layout
  are frozen in `ClassicControlKind`; changing them is a protocol change.
- **View layout.** The status travels as the stable `StationManagementCode` name, so reordering
  the enum cannot change its meaning. The values are the kind's exact count of bounded ints. No
  station UUID, name, owner or inventory is sent.
- **Beacon snapshot.** Beacon UUID, integer block position inside the world limits, a strict
  live flag (0 means last known or inactive) and a name of at most 32 printable characters. No
  owner or body is sent. C17c may still add the server side; the codec is frozen here.
- **Canonical frames.** A decoded view or snapshot must equal its own re-encoding, which rejects
  overlong VarInt string lengths and any other second spelling.
- **Wrong direction.** Forge closes the connection before decoding; each handler also checks its
  own reception side.
- **No new codes.** A request for another target than the menu's selection is refused as
  `STATION_CHANGED`, and Confirm uses `WARP_NO_CONFIRMATION` and `CONFIRMATION_MISMATCH`, so no
  language entry or `runData` change was needed.
- **Withdrawal reaches the command.** A quote the screen issued and stopped showing cannot be
  confirmed by `/arce station warp confirm` either. This is the conservative reading of
  "invalidates it".
- **View rate.** A changed view goes out at most every 5 ticks, unless an action or the opening
  forces it. The observed station moves on only when the holder's view matches it, so an action
  against a change the holder has not seen is refused as `STATION_CHANGED`.
- **Lost authority.** A registry that is no longer operational also closes the menu.
- **Panel size.** 256 by 222, the height of a vanilla six-row chest, so it fits a 720-pixel
  window at GUI scale 3.
