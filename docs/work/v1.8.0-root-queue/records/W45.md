## Choices where the task or ADR was open

- The task names `docs/provenance/v1.8.0-c18d-sounds.json`, which does not exist. The record that lists
  the `sounds.json` is W16's batch record, `v1.8.0-c18d-presentation.json`, so that is the one updated.
- I kept `ClassicSound.location()` and made it equal `registryId()`. The callers still name the concept
  they use (a sound location), and they needed no edits.
- The jar check is a unit test reading `arce.runtimeJar`, as `V180KernelRecipeResourcesTest` does. It is
  not in `scripts/validate_build_artifact.py`, because that generic validator also audits older release
  artifacts, which correctly carry the v0.1 file.
- "Copy `ui_select` exactly": the v0.1 entry sets no volume, pitch or stream value, so the defaults apply
  in both files. The test compares the parsed definitions, and the builder calls are the v0.1 ones.

  `/playsound advancedrocketrycommunity_v180:<id>` or a resource pack overriding the `_v180` sounds.json,

  migration is needed.

  exclusion would make `processResources` fail on the duplicate path. The jar test would also catch a
  second copy.
