## Design choices

C6 is commit `c8fa16e16be87554f26c402546733df6555d15e6`, with JAR SHA-256
`9f7e9d1ef708e27fa5778ca3c72ea3b3605f889465ae0d0d1054a890eb808dd4`.
The generator rejects another JAR. It reads current pattern JSON from that JAR, rather than copying historical source.
The controls use the current screen/menu Java layouts, Minecraft's effective-scale limits, ceil GUI dimensions,
Java integer truncation and logical control centres. The three settings are 1280 by 720 at scales 2 and 3,
and actual 1920 by 1080 fullscreen at scale 4. Fullscreen and font state remain runtime prerequisites.

All structures, supplies, initial vent energy/oxygen and railgun energy are disclosed fixture grants.
The offline `ArceTester1` UUID is not a premium account claim. Cygnus X-1 is a station orbit context inside Space,
not an invented dimension. The two stations are administrative setup; station UUIDs are native receipts, not deterministic output.
Generated commands and requests are deterministic. Saved Minecraft worlds, random native identifiers and timing are not byte-reproducible.

The integrated save is copied separately and enables cheats/creative mode only in that copy. Escape-menu pause
has bounded observations and no slash commands while paused. The tracked launcher copies saves but replaces options;
the later operator must confirm actual fullscreen, non-Unicode font, sound volume and pause-on-focus-loss settings.
No ADR decision or performance budget was changed.
