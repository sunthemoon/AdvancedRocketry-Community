All 908 Appendix A paths, hashes and source-resource bytes were checked against that JAR. Code and resources in this branch are unchanged from C5.

Records use schema 2 as required by [ADR-061 sections 4.3–4.5](../../../decisions/ADR-061-CLASSIC-CONTENT-IDENTITY-IMPORT-AND-VALIDATION.md). They retain the schema-1 required entry fields and add explicit JAR paths and audit asset IDs. Each entry pins its actual generator or manual authoring file, the matching source-file snapshot/hash, its authoring commit and parent/base identity. NEW entries use that parent as `source_commit`; GENERATED entries use the pinned generator snapshot. The batch-level source commit identifies the C5 capture, not a claimed original upstream author. Direct project generator/helper dependencies are pinned separately.

Artwork emitted from original community pixel rules is NEW; ordinary model/state/translation/profile output is GENERATED; the two source-authored v1.1 language files are NEW text. Material and planetary model delegates are recorded under the class containing the authoring rules, with dependencies retained. No upstream identity is invented. Existing complete records and the 13 assets with matching Markdown/supplementary inventory pins are left unchanged.

Every new review block is `PENDING_HUMAN_REVIEW`, has null reviewer/date, and binds a canonical SHA-256 digest of the entire record except its review block. The canonical format is UTF-8 JSON with sorted keys, compact separators and a trailing newline, matching the existing importer convention. Hash checks, source inspection and sheet preparation do not approve originality, licensing, visuals, a Gate or a release.
