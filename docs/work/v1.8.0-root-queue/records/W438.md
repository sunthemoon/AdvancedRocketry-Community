## Scope and design

The driver verifies the immutable parent's checksum list before copying, pins C6
commit `c8fa16e16be87554f26c402546733df6555d15e6` and JAR SHA-256
`9f7e9d1ef708e27fa5778ca3c72ea3b3605f889465ae0d0d1054a890eb808dd4`,
and only gives registered commands to the disposable server. It never serializes
NBT, SavedData or region files. Closed native files are read solely for evidence.
Each build saves and stops before exporting its source copy; qualification opens
a further copy, without test properties. Original source files are never reopened
by a server. The manifest contains commands, returned identities, readbacks,
parent checksum-list hash and C6's shipped body/route/satellite/sky resource values.
Each run retains configuration, logs, a file inventory and a native authority
projection. Existing runtime directories are refused, not deleted.

The new owner parameters default to `04380000-0000-4000-8000-000000000001`
and `04380000-0000-4000-8000-000000000002`. They are disposable placeholders,
not authenticated O5 accounts. FI05's inherited research owner is
`04360000-0000-4000-8000-000000000001`.

### The four state meanings

- Research accounts are private to `owner_id` in
  `data/advancedrocketrycommunity_satellite_missions.dat`, including balance and
  lifetime earned/spent totals. Discovery is world-wide in
  `data/advancedrocketrycommunity_celestial.dat`. A second owner in FI05 does not
  make Mars/Venus undiscovered. R614's fallback therefore selects FI04 for the
  undiscovered variant, keeping both stores and all original balances intact.
- The discovered variant retains FI05's earned Mars/Venus discoveries and the
  inherited account's 40 balance, 240 lifetime earned and 200 lifetime spent.
  Private station access is separate from shared discovery. The private variant
  uses the registered permission-2 admin-create command for the new owner and
  checks its returned ID, Mars orbit, owner, zero members and zero invitations
  against the native station store. It is an operator-created station, not an
  ordinary player purchase or proof of O5 ownership.
- Paid-pending means one earned data mission is `claim_pending_discovery` in the
  satellite store after its 120 award and 100 fee, while Mars is still absent
  from celestial discovery. The existing C6 `registry-writer discovery-launch`,
  `status`, `discovery-claim` and `hold-discovery true` hooks are named explicitly.
  The hook fixes its actor to `00000000-0000-0000-0000-000000129b01`; frozen
  production code is not changed to parameterize it. Normal scheduler ticks,
  rather than `discovery-ready`, finish the mission. The volatile hold prevents
  replay only; no paid receipt is synthesized. A no-hook reload should finish
  that same receipt without paying again. Qualification allows only that status
  transition and the new Mars discovery, retaining exact account totals.
- A blocked binding is a refused catalog adoption, not a corrupt or unwritable
  SavedData store. The existing K06 `data_only_test_mars.zip` reserves another
  identity. Disabling it retains that reservation. Enabling K06's `catalog_128.zip`
  then exceeds C6's 128 lifetime bindings. Disabling the refused pack is the
  supported recovery; no ID is erased or backup selectively merged. The source
  retains the reservation and refusal receipt, not a permanently blocked server.
  Qualification repeats the same refusal and recovery before comparing authority.

The shipped planetary dimension height is 256, not the Overworld's height. Site
heights are checked against the pinned JAR before launch. Read-only region
inspection confirms all four standpoint columns are air from y=244 through 255,
apart from the declared Venus roof at y=244. This is not a live sunlight/damage test.

C6 defaults read from `EnvironmentalExposure` are cold below 240 K, heat above
330 K, pressure above 2 and direct-sun solar intensity above 1.5; one 2-point
environmental attempt per 20 ticks, priority pressure/heat/cold/solar. Warning
heartbeat is 100 ticks. Vacuum defaults to 2 points per 20 ticks, and a coincident
suffocation attempt suppresses the environmental attempt. Mars is 210 K,
0.006 pressure, 0.43 solar and 0.38 gravity; Venus is 737 K, 9.2 pressure,
1.91 solar and 0.90 gravity. Radiation remains metadata, not another damage source.

The equipment plan names the complete `space_suit_helmet`,
`space_suit_chestplate`, `space_suit_leggings`, `space_suit_boots` set, filled
through normal equipment actions, with empty-tank and no-suit controls. Passive
protection requires all four correctly slotted pieces and the full built-in set
grants all three protection tags. An incomplete set also loses oxygen protection.
Consequently an unprotected Mars/Venus site does not prove isolated thermal,
pressure or solar damage; mask combinations do not prove additive damage.
No selective tag pack, custom hazard catalog or oxygen NBT is invented to make
those cases appear built. Oxygen-filled equipment, controlled rooms, live
isolated/combined damage and V1/V2 observations remain campaign work. K06 owns
sky/catalog pack construction; K18 owns packet/pending-menu tooling.
