## Design decisions and changed files

`advancedrocketrycommunity.bayV2CampaignPlayers` selects exactly two distinct canonical hyphenated UUIDs, separated
by one comma without whitespace. A malformed set value refuses native dedicated startup even with hooks off.
Unset preserves the facility-only policy; GameTest and integrated servers ignore the property. The gate retains
owner-thread, hooks, dedicated-server and RCON checks. Named connections may coexist with exact facility-owned
connections, but acquire no facility ownership; any third unowned connection closes the gate.

The world root's regular, non-symlink `.arce-bay-v2-campaign` must contain exactly the ASCII bytes
`ARCE_BAY_V2_DISPOSABLE_WORLD_V1\n` (LF, no BOM). Its bounded read and UUID selection are sampled at startup, stored
per server and cleared at stop. Startup and named-login INFO lines include property, both normalized UUIDs, absolute
world root and marker result. Unset emits neither line. This marker is operator acknowledgment, not proof of copying;
never mark the source world. Changes require restart. These choices implement R298, not a new ADR decision.
