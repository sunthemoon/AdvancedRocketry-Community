## Choices where the ADR was open

The note's section 8 lists all eleven, each with its reason. The ones Root should look at first:
- **Processor I/O cells.** The processor's legacy `'I'`/`'O'` cells are `machine_casing`, not item ports. ADR-066 names
  "input/output equivalents", but analysis moves no items. Only the fixture changes if Root prefers ports.
- **Blocks that no longer exist.** Tower cells are casing because `block:structureTower` has no successor block. Lens
  cells are exactly `minecraft:glass` because `blockLens` became an item.
- **Observatory shell.** The legacy `'*'` cells use a new tag, `observatory_shell_parts` (casing, iron block, power
  plug), following the arc furnace's shell tag.
- **The "existing persistence barrier".** It is read as the ADR-050 save-epoch gate before the first paid advance,
  with no new synchronous flush.
- **The migration's budget snapshot.** It refuses on record, root, list or reader bounds, not on section byte budgets,
  which stay admission bounds as today.
