fixture now explicitly supplies `locked="false"`; previously it omitted the newly
required unlock observation. None of its assertions was changed or removed.

The receipt implementation is commit `83e2acb18887b8ff11d7cfda849e1d52fc781824`.

Finding 2 adds shared `install_candidate` and `recheck_installed` helpers in
`scripts/bay_integrated_evidence.py`. They verify the owned session copy against
the already supplied hash. All three bay runners, the cargo fluid, settlement,
item and owner-cap controller, the shared loader and S6 controllers, G2's fuel-loader
S1 controller, and W336 use them. Each launch records the installed file and hash,
rechecks that file before process construction, and rechecks it before accepting
the invocation. W336's historical starts additionally require their own explicit
hash. Failed W336 construction cleans only its owned session and records failure.
The clean-worktree check and exact candidate-commit production-diff checks are
unchanged.

The added installed-candidate regression suite passes nine tests, including every
copying controller's input-replacement refusal before any process construction,
copy-time replacement with the input restored, installed-file tampering, historical
pinning, and positive launch metadata. The expanded family selection passes 527
tests from 44 files (bay, cargo, item, shared loader, W336 and campaign driver),
with no failures, errors or skips. The selector and complete file list are retained
externally as `verify_python.py` and `python-targeted-results.json`.

Several existing orchestration fixtures used literal `hash` or `b` instead of the
fixture JAR's SHA-256. The new installed-file check correctly refused those formerly
accepted placeholders. Only their hash inputs were corrected, with assertions and
case counts unchanged: `test_first_failed_cut_retains_three_starts_and_stops_before_next_cut`
in `test_cargo_cuts_runner.py`; `run_failed_cut`, used by three tests in
`test_cargo_s4_s5_cuts_runner.py`; `test_first_contradiction_retains_both_restarts_and_never_starts_next_cut`

in `test_loader_s6_oracle.py`; and `test_candidate_is_installed_before_an_adapter_can_start`
in `test_w336_native.py`. No test, assertion, timeout, budget or production oracle
was removed or loosened.

The installed-JAR implementation is commit `7fda15759ec69de3eb74cf0208e239f42591d8c7`.
