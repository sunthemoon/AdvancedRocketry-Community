## What was checked

1. **Nothing else changes.**
   - Only seven harness files and one new test file differ. `cells.py`, `launch.py` and every earlier test are
     byte-identical.
   - The review built the launch plan for W498's empty Forge profile and its Vanilla profile with the parent's code
     and with W501's code. The baseline identity, parsed session, 67-argument command line, game directory listing,
     `options.txt`, natives and decoded `level.dat` are byte-identical (both outputs have SHA-256 `0067454b…cca3`).
   - A candidate session that names `paired_world` is refused, as it was before (the message is new).
2. **The pairing copies only what it says.**
   - For the five accepted worlds (K04 64, 512, 2048 and multi, and K16 v2), every value in the new world that differs
     from the default world equals the source value: the seed, the two generation flags, the overworld generator,
     spawn, `Time`, `DayTime`, weather, the border, `DifficultyLocked` and the game rules.
   - The new world holds only `level.dat`, the pack list `vanilla` and the three vanilla dimensions. The six ARCE
     dimensions, `forgeLifecycle`, `ServerBrands`, `WasModded`, `DragonFight`, `CustomBossEvents` and
     `ScheduledEvents` are not copied.
   - A synthetic `Player` with an inventory, UUID, effects, Forge capabilities, a vehicle and attributes comes out
     with exactly `Dimension`, `Pos`, `Rotation`, `abilities` and `playerGameType`.
   - K07 and K21 are refused for their extra packs, as W501 records.
   - Each source `level.dat` had the same bytes, modification time and folder listing after the check. The code opens
     it only for reading and hashes the bytes it decodes (`baseline_pairing.py:150-153`).
   - Of 34 hostile synthetic worlds, the 11 accepted ones are vanilla forms or carry extra data that is dropped.
     Refused were modded and unlisted blocks, extra fields, inline or foreign noise settings, other biome sources,
     mod game rules, wrong types, non-finite values and another `DataVersion`. Trailing bytes, a second gzip member,
     a wrong pin, another file name, a directory and a junction are refused too.
3. **The JEI-only profile is pinned.**
   - The profile holds six files, and their hashes match W501's table and the manifest hash `e84cd1e3…c4f8`.
     `delivery-inputs.json` lists all 34 other files with correct sizes and hashes (32,734,756 bytes in total).
   - The JAR equals the JEI JAR of both P3 JEI cells, declares `modId="jei"` version 15.56.0.205, and nests no JAR.
   - The build scripts import only the standard library and the harness, and copy from
     `D:/GitHub/ARCE-Task-Evidence/root-queue/P3`. They contain no network call. The profile holds no account or
     launcher file, and the planned command line uses the offline name, `--accessToken 0` and `--userType legacy`.
   - On copies of the profile, 13 added files (in each game directory, at the top of the client folder and in the
     runtime), a renamed JAR, a changed JAR with a relabelled manifest and seven manifest edits were all refused.
     The only edit accepted is finding 3.
   - The launch copy's `mods` holds exactly the pinned JAR, and its other directories are empty.
4. **Receipts.** `dumps(pairing_identity(...))` parses back as JSON for the five real worlds and for every accepted
   synthetic world, including one with a saved `Player`. W501's test reads `summary.json` after READY with a paired
   JEI session.
5. **Tests.**
   - 227 tests pass (194 earlier and 33 new).
   - The diff of `tests/` apart from the new file is empty.
   - The new file has no Windows-only call, skips its two symlink tests where links are unavailable, and needs
     Python 3.11 or later; the workflows use 3.12. It was not run on Linux, because this machine has no WSL.
6. **README and record.**
   - The README matches the code, apart from the sentence in finding 5.
   - W501's table matches W500's `integration-blockers.json` reason by reason: the two JEI baseline sessions gain
     the missing capability, and the three flight sessions, the model session and the two JEI video sessions stay
     blocked for reasons this change does not touch.
   - The comparison block is truthfully "partially unblocked". Read it as follows: of W500's three seeds only
     20261006 can be paired now. The K07 world (row E11) and the K21 world (row D03) stay refused.
