forces, reads back and atomically moves that file on IO; a normal in-flight
staging file is not a production error. The fixture must wait before taking it.

It now drains its installed registry before placing its obstacle as well. The
search found no other GameTest creating a directory at this registry's pending
path. No production defect requiring a new design note was identified.
