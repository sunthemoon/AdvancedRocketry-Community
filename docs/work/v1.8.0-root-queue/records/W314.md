## Design and changed files

All Java paths are under `src/main/java/io/github/sunthemoon/advancedrocketrycommunity/`.

- `gametest/SkyWeatherFixture.java` is a per-test terminal listener, not a global collection. It restores on success,
  failure or timeout, attempts every cleanup action and preserves the original failure. It snapshots day time, weather
  flags/timers and both raw interpolation endpoints, including raw thunder when rain is zero.
- The helper clears and records the entire UP column within the top 16 build-height cells, with a 32-cell hard cap,
  and rejects unloaded or block-entity-bearing cells. Restoration suppresses neighbor/shape updates. It never adds a
  ticket or loads a chunk.
- The research helper owns the 27 quart-biome samples around the lens, covering BiomeManager's adjacent-sample choice.
  It uses the same native biome-fill, dirty-marking and viewer-resend APIs as `fillbiome`, preserving every other sample.
  `ResearchEnvironmentGameTests.java` uses this wet area and terminal cleanup instead of success-only roof removal.
- `SolarArrayGameTests.java` uses the recorded sky column, explicitly clears weather flags/timers before its natural
  wait, and uses terminal restoration. Its existing generation, storm, overflow, night and deliberate-roof assertions
  are unchanged.
- This record is the only documentation change. No registry, build, resource, schema, migration, protocol, asset,
  provenance entry, expected-log allowance or ADR decision changed. The task left the fixture technique open; the
  bounded native biome edit and controller sky column were chosen instead of relocating either fixture.
