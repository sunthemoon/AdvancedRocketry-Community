candidate checks, not full captures) reserves the existing 16 MiB byte budget;
non-container blocks charge one visit. It shares the runtime budget, changes no
limit, and preserves the first matching-slot pass before empty slots. Selection
finishes before the preparation ticket's existing lifetime starts. This deliberately
conservative reservation favors bounded work over throughput; later benchmarking
may measure a tighter reservation, but this slice does not alter the budget.
