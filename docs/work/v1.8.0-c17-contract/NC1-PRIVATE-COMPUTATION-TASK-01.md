## Proposed API and bounded behavior

Package-private final class and static `inspectOwned(CompoundTag)` /
`encodeOwned(CompoundTag)` only; nested Inspection/Status/Reason types follow
contract section4 exactly. No hash method, arbitrary caller budget or public API.

- One fixed BE-data ceiling: existing RocketLimits 262,144 named bytes.
  Derived occurrence/depth counters cannot narrow this byte allowance.
- All12 exact native classes; exact-class checks precede child accessors.
  End/foreign/null/cycle/typed-empty/mismatched lists refuse without normalization.
- Modified UTF65535; unsigned ordinary UTF8 key order with original UTF16 tie;
  original units emitted, no replacement/fallback. Big-endian native payloads.
- Noncanonical NaN raw bits refuse; canonical NaN/infinities and pure signed-zero
  bytes retain their exact rules. Pure output does not permit native reload.
- Iterative lazy traversal, active-ancestor identity tracking, alias occurrence
  expansion, checked arithmetic, bounded key scratch and exact-sized fresh output.
- Exclusive stable transitive ownership is a precondition. CHANGED covers only
  observed inconsistency, not guaranteed same-size race detection.
- Refusal returns zero partial measurements or throws the fixed bounded message;
  no input-bearing cause, partial output, mutation, repair, log or retained alias.
