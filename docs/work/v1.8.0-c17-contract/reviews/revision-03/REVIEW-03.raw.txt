## Remaining decisions / limitations / next scope

- D2-A product behavior is owner-confirmed; this review does not supply technical
  owner acceptance. D1, D1-disassembly and D3 remain pending choices. Their
  unresolved semantics are not automatically selected by a zero-findings result.
- Exact D3 durable writer/receipt/barrier admission, native clock save/restart/
  unknown/stale-serializer tests, API compatibility, leaf recipes/patterns, source
  licensing and performance/visual Gates still require work. C18's D2/D3 and D4
  feasibility limits remain independent. Conditional first-event outboxes need
  one shared integrated schema freeze; no existing setDirty call is a barrier.
- Abrupt-stop visual rewind to the surviving coherent checkpoint is an explicit
  limitation, not a hidden timing guarantee. Implementation must preserve this
  authority model and test it rather than weakening native save assertions.
