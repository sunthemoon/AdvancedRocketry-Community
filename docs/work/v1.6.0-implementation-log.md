# v1.6.0 implementation log

## Goal and scope

Deliver [Satellites & Resource Missions](../versions/V1.6.0-SATELLITE-RESOURCE-MISSIONS.md):
constructable and deployable satellite kinds, a bounded offline scheduler,
asteroid and gas-giant resource missions with reproducible, conserved rewards,
and recovery across cancellation, restart, upgrade and definition change.
Development evidence does not approve a release or remove inherited Required Gates.

The v1.5 handoff is a development baseline, not a passed prerequisite.
[ADR-048](../decisions/ADR-048-V160-DEVELOPMENT-BASELINE-EXCEPTION.md) separately
authorizes this version once accepted. Root is the sole tracked writer.
Independent review uses read-only repository access and fresh Temp outputs.
The untracked user documentation bundle remains excluded from reads/writes.
No upstream code or asset is imported.

## C6 — preparation and contracts (this chunk)

Done in preparation:

- Branch created from the v1.5 closure commit `940a5ed`.
- Read-only [legacy audit](v1.6.0-legacy-audit.md): 43 upstream files fetched from
  the pinned MIT commit into Temp, all 43 hashes equal to `legacy-manifest`; two
  guessed paths were absent and are recorded as such.
- Contracts drafted: ADR-048 (baseline exception), ADR-049 (kinds, components,
  blueprints, builder, survey scan, solar receiver), ADR-050 (scheduler,
  lifecycle, retention, cancellation, timeouts, quarantine, migration), ADR-051
  (logical asteroid instances, gas harvesting, bound-terminal delivery and
  reconciliation), ADR-052 (tables, seeds, `survey-v1`/`asteroid-v1`/`gas-v1`).
- [Reference vectors](v1.6.0-preparation/examples.json) with a standard-library
  [checker](v1.6.0-preparation/check_examples.py): SplitMix64 against its published
  seed-0 outputs, bounded draws, survey/yield vectors, truncation, durations, gas
  amounts, blueprint rules, backlog passes and the reconciliation table.

Explicit C6 non-goals: any change to production Java, resources, build scripts or
generated data; the runtime version; world migration; new items or blocks; asset
imports; candidate, tag or Gate changes; remote, long-load or real-client tests.

Findings recorded for the contracts:

- The current registry never prunes finished missions, so it locks at 8,192
  records (fixed by ADR-050 §6).
- The 4 MiB registry bound is enforced only by an exception at save time (ADR-050 §6).
- Item rewards cross from SavedData into a block entity; the delivery protocol
  and its crash-cut table are in ADR-051 §6.
