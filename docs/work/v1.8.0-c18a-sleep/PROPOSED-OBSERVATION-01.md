## Outcome and precise evidence class

Observe installed Java 17 /Forge 47.4.10 native spawn-event call frames and native
before/after outcomes in a fresh disposable packaged Overworld. An opt-in separate
adapter fixture uses a native PlayerList-registered ServerPlayer with its own open
EmbeddedChannel, then invokes the public native ServerGamePacketListener packet
handler on the owning server thread with a test-owned use-on packet.

This is **native-Java simulated transport**, not TCP receipt, a decoder/scheduling
test, real client login/input/acknowledgement, multiplayer/GPU or full B1 proof.
Connection.isConnected and PlayerList identity do not upgrade that evidence class.
Direct game-mode/sleep calls and synthetic events are negative/ordering controls
only; they must never replace a missing observation of the stated handler route.
No direct startSleeping, pose setter or manual PlayerList NBT load is permitted.

The observer only reads a bounded current-thread stack and the current event.
It does not cancel/uncancel, set sleep/time results, suppress native updates,
restore spawn fields, grant air or implement a MATCH-based gameplay decision.
Frames can be compared afterward with the proposed class/MethodType fingerprint;
that comparison is not architecture adoption or an INDETERMINATE policy.

## Bounded trace and temporary listener semantics

Public Java StackWalker RETAIN_CLASS_REFERENCE is the only proposed introspection;
no reflection/private access, AT, mixin/coremod or intercepted native method.
Record frame declaring class, actual method descriptor and diagnostic member name
without using remapped names as a cause predicate. Retain at most 64 frames plus
one overflow sentinel, at most 32 trace records and 128 KiB structured trace per
stage. These are test-only limits, not approved production performance budgets.
Truncation, unavailable metadata or permission failure produces an explicit
incomplete observation; no success/cause guarantee is inferred from it.

Capture the exact event actor/Level/position/forced tuple, cancellation and current
fixture identity. Attribute nearest dispatch and nested events separately rather
than matching any enclosing bed frame. A LOWEST/receiveCanceled observer is not
exclusive final state: capture completed native state after the action as well.
No event mutation or speculative scan/provider callback belongs in the observer.
Frame metadata alone identifies neither the callback argument's origin nor an
inherited BedBlock receiver. Trace actual event/actor identity separately and
include explicitly labeled forwarding/direct-callback and inherited-bed controls,
or record a supported-boundary exclusion in the later assignment. Such controls
can expose indistinguishable metadata; they cannot be reported as exact cause
proof simply because a bed frame is present. Native event construction and the
observer's callback wiring must be part of the reviewed identity evidence.
Measure frame count and observation time/allocation when a supported public
measurement is available; otherwise mark allocation unmeasured. No tick logger,
global player action marker or second persistence truth store is introduced.

Temporary negative-control listeners are registered only for their named fixture
phase. Nested setters/synthetic events have a finite explicit recursion guard and
are separate test interventions, not passive-observer actions. Unregister exactly
owned listeners in finally, restore owned fixtures and remove/drain/release only
the owned player/connection packets. Never clear or reflect into the global bus.
Observer exceptions cannot turn a failed native action into a PASS; preserve
failure and subsequent cleanup results. No listener survives the synchronous
stage or a later unrelated console invocation.
