# v1.3.0 implementation log

## Goal and scope

Deliver the public API and compatibility scope in the
[version plan](../versions/V1.3.0-PUBLIC-API-COMPATIBILITY.md), beginning with an
explicit exported boundary and an independent consumer. Development proceeds
under accepted ADR-020/021; complete inherited acceptance remains outstanding.

The original proposal checkout is not the completed v1.2 implementation baseline.
The accepted baseline includes the reviewed v1.2 implementation and evidence;
it was merged without replacing the proposal documents or user-supplied files.

Non-goals: implementing future machines/dimensions, changing save or network
contracts, releasing/tagging a version, running deferred full acceptance, or
exposing every existing Java `public` type as supported API.

## Decisions and blockers

On 2026-09-26 the owner authorized recommended solutions. The recommended
development exception and minimal API policy were accepted separately as

implementation choices should follow the recommended approach without repeated
approval requests; releases, Gate approval and incompatible scope changes remain
separate decisions. ADR-018's full-test scheduling is unchanged.
