## Decisions and blockers

The development-sequence approval and API-contract approval are separate.
An empty baseline is deliberately not an approval-ready development exception.
After permission to organize the existing v1.2 changes into development commits,
record and inspect the exact full implementation commit before accepting ADR-020.
Do not substitute this older documentation checkout, a JAR hash or an uncommitted
source inventory for that commit.
