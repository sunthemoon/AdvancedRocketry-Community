## Remaining client case

Use a clean visible test profile containing only Forge 47.4.10 and this project.
The development run can use an isolated directory and fixed window size:

```bash
./gradlew -ParceEvidenceRun=true runClient --no-daemon --stacktrace
```

1. Open **Mods**, select **Advanced Rocketry: Community Edition**, and capture
   the full Minecraft window showing name, version, description, credits,
   license, and logo.
2. Create a disposable single-player world, wait until the player is in-world,
   capture the full Minecraft window, save, and return to the title screen.
3. Review `build/client-evidence/game/logs/latest.log`; record project-source
   ERROR/WARN counts and explain accepted Forge development warnings.
4. Copy only the Minecraft screenshots and selected UTF-8 log excerpts into
   `docs/releases/v0.0.2/evidence/client/`. Do not capture unrelated desktop
   windows or credentials.

If an existing disposable world folder is available under
`build/client-evidence/game/saves/`, it can be opened directly:

```bash
./gradlew -ParceEvidenceRun=true -ParceQuickPlaySingleplayer=<world-folder> runClient --no-daemon --stacktrace
```

## Remaining player-connection case

Run the packaged server produced by the smoke harness in a disposable test-only
instance. For a local development identity, set `online-mode=false` and
`enforce-secure-profile=false`; never reuse those settings for a public server.
Start the installed server with Java 17:

```text
Windows: java @libraries/net/minecraftforge/forge/1.20.1-47.4.10/win_args.txt nogui
Linux:   java @libraries/net/minecraftforge/forge/1.20.1-47.4.10/unix_args.txt nogui
```

Then connect the matching development client, replacing the port with the
disposable server's configured port:

```bash
./gradlew -ParceEvidenceRun=true -ParceQuickPlayMultiplayer=127.0.0.1:<port> runClient --no-daemon --stacktrace
```

Required observations:

- server log records the development player joining with the final artifact;
- client reaches the world without a mod mismatch;
- disconnect, `save-all flush`, and `stop` complete normally;
- server restarts the same world, and the matching client reconnects;
- no project-source ERROR or client-class linkage failure occurs.

Archive selected join/disconnect/restart excerpts under
`docs/releases/v0.0.2/evidence/dedicated-server/`. Then update
`MANUAL-TEST.md`, `TEST-REPORT.md`, `RELEASE-EVIDENCE.md`, `GATE_STATUS.md`, and
this handoff. Only a human may mark all Required Gates `PASSED`.
