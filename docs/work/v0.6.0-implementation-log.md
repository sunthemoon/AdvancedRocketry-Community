# v0.6.0 Implementation Log — Earth–Moon round trip

## Goal

Deliver the first playable, server-authoritative Earth–Moon round trip: fuel a
v0.5 block rocket, select a fixed destination, launch, transfer passengers,
land, return, disassemble, and recover safely after disconnects or restarts.

## Scope and non-goals

In scope: bounded fuel loading, flight planning/state, fixed Earth/Moon pads,
durable cross-Level transfer, passenger UUID/seat bindings, destination UI,
auditable feedback, landing/disassembly, restart recovery, security tests, and
release evidence.

Out of scope: Space travel, arbitrary planets or coordinates, orbital physics,
stations, satellites, combat, dynamic dimensions, third-party BlockEntity
movement, and any relaxation of v0.5 structure/NBT limits.

## Assumptions and accepted decisions

- v0.5.0 is `PASSED`; this branch starts from
  `b349789c9d330da782c8e719f57ff09d8a262e7f`.
- Earth and Moon use the fixed Levels accepted by ADR-001.
- ADR-006 defines the durable authority boundary and four-case recovery matrix.
- Transit may use a short state/loading transition instead of continuous
  cross-Level interpolation.
- All new resources are community-authored DataGen output; no upstream files
  are copied in this version unless a separate provenance record is added first.
