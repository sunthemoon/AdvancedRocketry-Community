# v1.5.0 implementation log

## Goal and scope

Deliver [Orbital/Station/Warp](../versions/V1.5.0-ORBITAL-STATION-WARP.md):
usable arbitrary-body stations, bounded expansion/access, actual orbital
environment and presentation, and costed multi-star warp with recoverable assets.
Implementation precedes the deferred all-content campaign; development evidence
does not approve a release or remove inherited Required Gates.

```yaml
last_updated: 2026-09-28
```

The v1.4 handoff is a development baseline, not a passed prerequisite. Accepted
ADR-039 separately authorizes this version; ADR-040 freezes only station foundation.
Runtime permission applies only to accepted current-version contracts; later
public/persistent changes still need their own decisions.
Root is the sole tracked writer. Independent review uses read-only repository
access and fresh Temp outputs. The untracked user documentation bundle remains
excluded from reads/writes. No new upstream assets/code are imported.

Preparation non-goals: production/build/resource edits, actual world migration,
orbit mutation, warp implementation, candidate/tag/Gate approval, remote or
long-load/real-client tests. The unchanged runtime still identifies as v1.4-dev.

## Open decisions and risks

- Warp's physical versus logical relocation, cost authority, persistent docking
  and inbound/unloaded flight reconciliation require WARP-01 before runtime code.
- Effective orbit values must resolve the valid stored 0..10 gravity range versus
  the existing 0..4 player controller, without changing public configured queries.
  Stored solar angle is not solar-power generation or current sky rendering.
- Existing station flush and malformed-registry build semantics are known source
  limitations, not fixed by preparation. ADR-040 assigns finite repair checks.
- Region growth can adopt pre-existing gap blocks; explicit confirmation and
  checked permission change do not establish ownership of every world block.
- Same-orbit stations share a route anchor and existing planner rejects equal
  anchors; station-to-station local travel must be deliberately dispositioned
  in the route/warp contract rather than accidentally promised.
